자동 실행을 중지한 상태예요.

기능을 선택하고 자동 실행을 허용해 주세요. PC가 켜져 있고 이 프로그램이 실행 중이어야 해요. 절전·종료로 기한을 놓친 작업은 몰아서 실행하지 않아요.

자동 입장 사이트

조회 후 오늘 예약을 갱신해요. 클릭·강의창 이동·재생 확인은 각각 기록해요. 한미는 시작·25분에 입장하고, 25분 회차의 명확한 실패 때만 35분에 한 번 더 확인해요. 후다닥·디톡스·닥플은 직접 열기와 조회를 이용할 수 있어요.

비밀번호를 저장하려면 사이트별 「계정 저장·복구」를 이용하세요. 휴대폰과 설정·실행 내역은 각각 관리돼요.

닥터빌 설문

개시 확인은 자동입장 실행이 확인된 강의에 적용돼요. 남은 시간을 확인한 열린 설문은 마감 약 10분 전에 한 번 더 확인해요. 설문 참여와 제출은 직접 해 주세요.

메디게이트 월간 수강 집계

공식 페이지를 자동으로 찾지 못하면 이번 달 행사 주소를 입력해 주세요. 빈 값으로 저장하면 자동 확인으로 돌아갑니다.

로컬 사용량 진단

X는 트레이에 숨기기예요. 업데이트는 버튼을 누를 때만 진행해요.

오류보고 미리보기

버전·작업 상태와 시도 결과를 확인해 주세요. 복사·저장은 현재 미리 본 내용을 사용해요.

계정 저장·복구

별도의 임시 프로필에서 실제 로그인을 확인해요. 보안 문자·추가 인증·오류가 나오면 저장하지 않아요. 휴대폰·평소 브라우저의 계정은 가져오지 않아요.

전체 자동 실행을 허용한 상태에서, 로그인 만료가 확인된 사이트만 복구해요. 비밀번호 오류·결과 미확인은 반복 제출하지 않아요.
