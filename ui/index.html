강의 조회

오늘 강의 조회·출석 상태 확인과 켜 둔 자동 기능을 함께 실행해요.

① 사이트 열기 → ② 사이트에서 로그인 → ③ 그 창 위쪽의 「로그인 마침 · 이 사이트 조회」를 눌러 주세요.

「로그인 마침」은 브라우저 세션 보관이에요. 아이디·비밀번호를 저장하려면 사이트별 「계정 저장·복구」를 이용해 주세요. 로그인 유지 기간은 사이트 정책을 따라요.

휴대폰과 설정·실행 내역을 공유하지 않아요. 양쪽에서 자동 실행을 켜면 같은 작업이 각각 실행될 수 있어요.

강의 목록

자동 실행

자동 실행을 중지한 상태예요.

기능을 선택하고 자동 실행을 허용해 주세요. PC가 켜져 있고 이 프로그램이 실행 중이어야 해요. 절전·종료로 기한을 놓친 작업은 몰아서 실행하지 않아요.

자동 입장 사이트

조회 후 오늘 예약을 갱신해요. 클릭·강의창 이동·재생 확인은 각각 기록해요. 한미는 신청된 강의 시작 기준 10분 간격으로 최대 5회 확인해요.

오늘 출석·퀴즈·브랜드관

오늘 자동 입장 예약·실행

X는 트레이에 숨기기예요. 패치 전에는 프로그램 종료를 눌러 완전히 끝내 주세요.

계정 저장·복구

별도의 임시 프로필에서 실제 로그인을 확인해요. 보안 문자·추가 인증·오류가 나오면 저장하지 않아요. 휴대폰·평소 브라우저의 계정은 가져오지 않아요.

전체 자동 실행을 허용한 상태에서, 로그인 만료가 확인된 사이트만 복구해요. 비밀번호 오류·결과 미확인은 반복 제출하지 않아요.
