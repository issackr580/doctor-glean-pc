# 의사 이삭 줍기 PC

Windows PC를 켜두고 사용하는 독립형 상주 프로그램. 기준 버전은 **0.1.0-preview.23**이다. 운영 서버·유료 API·모바일 동기화·자체 원격 조작·절전 해제를 사용하지 않는다.

## 공동 개발 시작

PC 전용 [공개 소스 저장소](https://github.com/issackr580/doctor-glean-pc)에서 브랜치와 PR로 작업한다. 쓰기 권한이 없는 개발자는 fork 후 PR을 보낸다. Android 제품은 이 저장소에 포함하거나 변경하지 않는다.

1. [CONTRIBUTING](CONTRIBUTING.md): 개발 환경·브랜치·PR·검사 기준
2. [현재 상태](docs/STATUS.md): 구현·검증·남은 문제·다음 작업
3. [구조](docs/ARCHITECTURE.md): 모듈·신뢰 경계·저장 형식·엔진 동기화
4. [개발 방침](docs/DEVELOPMENT_POLICY.md)과 [결정 기록](docs/DECISIONS.md): 확정 범위
5. [개발자 로그 수집](docs/DIAGNOSTICS.md): 재현 전 기록 켜기·JSON 내보내기·공유 기준
6. [배포 절차](docs/RELEASE_PROCESS.md)와 [이번 기록](docs/releases/0.1.0-preview.23.md): 소스 기준점·검증·릴리스

```sh
npm ci
npm test
npm run check
npm run test:electron
npm start
```

Node24/npm11을 사용한다. Windows에서는 Electron 검사를 그대로 실행하며 Linux에서는 DISPLAY 또는 Xvfb가 필요하다. 로그인·포인트를 실행하는 합성 검사에 실제 계정을 넣지 않는다. CI는 docs/ci의 수동 실행 예시로만 제공하며 기본 비활성이다. 자동 게시·정기 작업이 없다. 무료 실행 한도를 넘기는 유료 서비스 가입을 전제로 하지 않는다.

## 현재 기능

- 9사이트 강의 조회, 날짜·사이트 선택, 캐시·목록 복사·취소·로그인 마침 대기열.
- 출석·캡슐, 닥터빌 퀴즈 하루1회 제출, 인터엠디 퀴즈 상태 확인, 키메디 브랜드관 최대2회.
- 한 사이트 재조회·저장 계정 로그인, 예정 예약 일괄 사전 검사, 이번 실행/이전 클릭 구분.
- 준비 대기·문서 교체를 구분하는 읽기 전용 사전 검사, PC 실행·이동·영상·사이트 완료 구분, 상태만 새로 확인.
- 6사이트 자동 입장, 한미 시작10분 전 준비·시작부터10분 간격 최대5회·종료 중단.
- 오전08:10과 평일00:01:02 닥터라운지. PC·프로그램이 실행 중인 조건에서 정해진 기한만 처리.
- 별도 후보 검증 후 Windows DPAPI 계정 저장·동의한 만료 복구, 시도 전 기록·불확실 재전송 제한.
- 개발자/배포용의 저장소·코드 분리, 수동 전체/작은 패치, 자동 전송 없는 최소 진단.

기능은 기본 꺼짐이다. 클릭·목적지·영상 진행·적립 완료를 구분한다. 지속 영상 재생은 보류, 종근당 매일 새 로그인과 닥터빌 설문은 별도 검증 단계다. 사이트별 실제 성공 범위는 STATUS를 기준으로 한다. 모바일과 함께 사용할 때는 [PC 검증 방법](docs/ENTRY_VALIDATION.md)으로 새 실행 시각과 근거를 확인한다.

## 실행과 업데이트

[Windows 안내](docs/WINDOWS_PREVIEW.md)를 따른다. 배포용 실행물은 이 저장소의 [공개 검증판](https://github.com/issackr580/doctor-glean-pc/releases/tag/pc-v0.1.0-preview.23), 개발자용 실행물은 지정 collaborator가 GitHub 로그인 후 같은 [Releases 목록](https://github.com/issackr580/doctor-glean-pc/releases)의 **preview.23 협업자 전용 Draft**에서 받는다. 접근 권한은 [배포·협업 권한 기준](docs/ACCESS.md)을 따른다. 개발자용 실행파일을 공개 릴리스에 첨부하지 않는다.

작은 패치는 최신 resources/app 전체를 담는다. 릴리스에서 호환 검증한 같은 에디션의 이전 버전은 중간 패치를 거치지 않고 한 번에 올릴 수 있다. 완전 종료 → 기존 resources/app 백업 → 패치 app 전체 교체 → 하단 버전 확인 순서다. X는 트레이 숨김이다. 로그인·계정·시도는 별도 데이터 폴더에 유지된다. 첫 설치·호환 미확인 버전·runtime 변경은 전체 ZIP이다.

계정 저장 후 자동 복구를 허용하면 작업 프로필도 확인하고 해당 사이트 목록을 갱신한다. 이미 저장한 계정은 다시 입력할 필요 없이 **저장 계정으로 로그인**으로 확인한다. 최근 실패의 제한은 지우지 않으며 다음 가능 시각을 표시한다. 개인정보·원문·계정 파일은 Git에 넣지 않는다.

## 소스 인계

```sh
npm run source:pack
```

코드·문서·합성 검사·vendor만 허용 목록으로 묶고 SOURCE_MANIFEST에 해시를 기록한다. 실제 보고서·verification·브라우저·계정·키·실행파일·캐시는 제외한다. 문서와 코드가 같은 Git 기준점에 연결되도록 릴리스 태그를 사용한다. 공개 라이선스는 별도 결정 전 임의로 부여하지 않는다.

회차별 선택 보고·PC 합성 재현·현재 입력 SHA 검증과 수동 업데이트 확인은 [품질 흐름](docs/QUALITY_WORKFLOW.md)을 따릅니다.

미신청 강의는 입장 예약의 **신청하기**, 한미는 미신청 조회 목록에서도 신청할 수 있습니다. 사이트에서 최종 단계를 마친 뒤 **신청 마침 · 상태 확인**을 누르세요. [사용·검증 안내](docs/ENTRY_VALIDATION.md)를 따릅니다.

닥터빌 상세는 같은 대상 영역의 제목·독립된 날짜·첫 시작시각을 대조하고, 종료·기신청·미리보기 상태를 구분합니다. 외부 플레이어의 계정 생성·동의·추가 인증은 사이트에서 직접 마칩니다.
