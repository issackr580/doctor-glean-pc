# 의사 이삭 줍기 PC 로드맵

2026년 11월 24일 기준. Windows PC에서 신청한 강의를 놓치는 경우를 줄이고, 실행 결과와 접속 비용을 확인할 수 있도록 개선한다. 일정은 날짜나 버전 번호로 미리 확정하기보다 아래 완료 기준과 실제 사용 결과를 보면서 조정한다.

## 현재 기준

공개 배포용과 협업자용 개발자 Draft는 0.1.0-preview.39다. 10개 사이트의 강의 조회와 8개 사이트의 자동 입장이 연결돼 있다. 닥플 출석 상태와 복구 후 강의 목록은 HTTP를 먼저 사용한다. 메디게이트는 같은 달의 수강 집계가 늘면 자동 작업을 끝내고 외부 강의 주소를 개별 허용하지 않는다. 고정 소스에서 Node 466개와 Linux Electron 합성 검사 1,449개가 통과했다. 실제 Windows 설치·재시작과 회원 사이트 동작은 확인이 남아 있다. [preview.39 릴리스 기록](releases/0.1.0-preview.39.md)

## 우선순위

| 순서 | 개선 범위 | 완료 기준 |
|---|---|---|
| 1 · 실사용 기준 확보 | preview.39의 Windows 업데이트, 로그인 복구, 대표 예약 확인 | 같은 에디션의 업데이트 전후에서 계정·선택·예약·시도 기록을 대조한다. 정상 실행과 미확인 원인을 각각 확인할 수 있는 Windows 기록을 확보한다. |
| 2 · 놓친 강의와 중복 방지 | 취소·절전·시간 변경·여러 창·로그인 만료를 공통 실행 경로에서 점검 | 같은 공식 ID의 일정 변경은 최신 상세로 바로잡는다. 저장 실패나 취소 뒤 클릭 0회, 응답 유실 뒤 자동 재제출 0회를 재현한다. 신청 필요·사이트 대기·확인 불가를 결과에서 구분한다. |
| 3 · 데이터 사용량 줄이기 | 10개 사이트의 목록·상세·상태 확인을 함께 비교하고 확정된 읽기 경로를 전환 | 같은 계정·날짜·필터로 공식 ID·시각·신청 상태·전체 페이지가 기존 화면과 일치한다. 요청 전후 창 수·요청 수·본문 바이트를 비교하고, 실패 시 화면 대체와 사이트 대기 준수를 점검한다. |
| 4 · 운영과 배포 반복 개선 | 오류보고 재현, 필요한 회귀 검사, 서명된 두 에디션 업데이트 | 재현된 문제를 합성 회귀 검사로 남긴다. 같은 커밋의 배포용 공개 릴리스·개발자용 Draft·서명 피드를 검증하고 두 링크를 함께 전달한다. |

실사용 확인을 진행하는 동안 합성 자료로 재현되는 조회·예약·네트워크 개선도 병행한다. 계정·예약과 요청을 함께 바꾸는 작업은 GPT-6.2 Sol High를 기본 검토 수준으로 삼는다. [공동 개발 기준](../CONTRIBUTING.md) · [배포 절차](RELEASE_PROCESS.md)

## 첫 확인 묶음

| 항목 | 볼 근거 |
|---|---|
| Windows 설치·업데이트 | 같은 에디션의 새 설치와 preview.38→39 패치, 재시작 후 버전·프로필·선택·예약·시도 이력. 설치 실패 시 복원과 사용자 데이터 보존 |
| 메디게이트 11월·12월 | 월이 다른 집계의 배제, 다음 달 공식 링크 또는 월별 설정, 같은 계정에서 입장 1회와 집계 증가 후 종료. 강의 단위 검증 중 동일 계정의 다른 기기 수강이 있었는지 기록 |
| 닥터빌 | 저장 계정으로 만료 복구 후 선택일 조회, 공유 날짜 열, 일정이 바뀐 강의, 기존 채널 확인 1회와 같은 강의 대기실 도달 |
| 닥플·종근당 | HTTP 결과와 같은 날 사이트 화면의 날짜·시각·전체 범위 대조. 닥플의 출석 완료 확인과 미출석 후속 경로를 각각 확인 |
| 한미·디톡스 | 한미 시작 0분·25분과 명확한 실패가 있을 때의 35분 회차. 디톡스 날짜 열과 새로고침·재시작 후 정정 결과 |
| 공통 장애 | 429와 서버 지정 대기, 재시작, Windows 절전 복귀, 여러 창에서 같은 작업을 요청했을 때의 요청·클릭 수 |

실기기 확인은 앱 오류보고에서 버전·사이트·예정 시각·결과를 대조하고, 가능한 경우 사이트의 집계나 완료 내역을 함께 본다. 예약 생성, PC 클릭, 강의창 도달, 수강·적립을 각각 기록한다. 합성 검사에 실제 계정이나 쿠키를 넣지 않는다. [PC 입장 검증](ENTRY_VALIDATION.md) · [진단 공유 기준](DIAGNOSTICS.md)

## HTTP 확대 기준

닥플·종근당은 이미 연결한 경로의 실사용 결과부터 확인한다. 키메디 목록·상세, 메디게이트 회원 집계, 다른 사이트의 전체 목록은 공개 클라이언트에서 확인한 요청과 PC 계정의 실제 응답을 함께 검토한다. 인증·날짜·공식 ID·전체 범위가 확인된 조회부터 바꾼다. 입장·출석·신청은 기존 사이트 동작과 영속 원장의 통제를 받는다.

같은 조건에서 브라우저 창, 서버 요청, 응답 본문 바이트, 대체 경로, 성공·미확인 건수를 기록한다. 실제 PC 전체 전송량은 별도 관측값으로 남긴다. 진행 중인 동일 조회를 합치거나 이미 끝낸 사이트를 건너뛸 수 있는 공통 개선은 API 검증과 병행한다. [10개 사이트의 현재 조회 경로](PC_NETWORK_PATHS.md)
