# PC 데이터 사용과 사이트별 조회 경로

전체 목록을 대체하는 HTTP는 현재 PC 프로필의 권한, 조회 날짜, 공식 ID·시각·신청 상태와 응답의 전체 범위를 입증할 수 있어야 한다. 일부 HTML이나 공개 목록은 기존 결과를 덮는 근거로 사용하지 않는다. 실제 회원 응답이 없는 계약은 호출 방법과 공개 증거까지만 확인한다.

| 사이트 | 읽기 경로와 적용 범위 | 브라우저에서 확인하는 근거 |
|---|---|---|
| 종근당 | 로그인 허용 후 월간·선택일 HTTP 결과 대조 | 당일 로그인과 인증 상태. 월·일 결과가 맞지 않으면 원래 일정 화면 |
| 닥플 플러스 | LIVE 전체 페이지, 로그인 복구 직후 목록, 읽기 전용 출석 달력 | API가 불완전하면 원래 화면. 출석 신청과 강의 입장은 원래 버튼 사용 |
| 메디게이트 | 월간 참여 페이지가 직접 호출한 수강 집계 GET을 관찰. 공개 포틀릿은 부분 일정 | 회원 전체 목록, 원래 입장, 현재 월 집계와 실제 페이지의 수강 숫자 대조 |
| 키메디 | 공개 클라이언트에서 `tvList`와 `tvInfo` POST 및 목록 증가 방식 확인. 회원별 데이터와 전체 날짜·신청 범위를 확인할 PC 응답은 미확보 | 목록·상세·출석·브랜드관·라운지. 계정 복구와 라운지에서 기존 사이트가 발행한 응답의 상태 근거 사용 |
| 닥터빌 | 완전한 목록 API 계약 미확보 | 날짜 열·상세 시간, 퀴즈 결과, 같은 강의 대기실 판독. 설문은 수동으로 열기 |
| 한미 | 완전한 목록 API 계약 미확보 | 로그인·월/일 일정·등록·강의 원래 버튼·캡슐 결과 |
| 인터엠디 | 완전한 목록 API 계약 미확보 | 일정·퀴즈. 평일 퀴즈는 공개 전 접속 생략 |
| 후다닥 | 완전한 목록 API 계약 미확보 | 선택일 목록·상세와 신청·입장 상태 |
| 블루팜 | 완전한 목록 API 계약 미확보 | 모집·진행 목록과 종료 범위 |
| 디톡스 | 완전한 목록 API 계약 미확보 | 달력의 실제 화면 열에서 날짜 판독. 자동 입장 중지 정책 유지 |

동일 사이트의 반복 조회 요청은 같은 날짜·계정에서 진행 중인 작업을 공유한다. 사용자가 로그인을 마치면 새 세션의 조회를 예약한다. 자동 입장이 목록 조회보다 우선하면 완료한 사이트를 다시 열지 않고 중단한 사이트와 아직 읽지 않은 사이트만 이어간다. 이전 일부 결과, 사용자가 직접 보는 창과 실제 수강 요청은 각각 기존 근거를 사용한다.

## 메디게이트 월간 집계

11월의 초기 주소는 사용자가 제공한 공식 행사 페이지다. 다른 달에는 이미 연 공식 사이트의 현재 월 웨비나 링크를 확인한다. 공식 사이트가 링크를 표시하지 않으면 앱에서 이번 달 행사 주소를 저장할 수 있다. 저장한 주소는 해당 연·월에만 적용한다. URL의 숫자에서 월이나 새 주소를 추측하지 않는다.

입장 전후 같은 PC 프로필에서 행사 페이지가 원래 요청한 신선한 GET 응답과 화면 안의 `나의 웨비나 참여 현황` 수치가 일치해야 한다. 입장은 기존 원장에 기록하고 원래 버튼을 한 번만 실행한다. 다른 서비스의 강의 주소를 자동 허용하지 않으며 팝업과 프레임 탐색도 공식 호스트로 제한한다. 외부 이동이 차단돼도 별도 수강 집계를 확인할 수 있다. 집계가 늘면 창을 닫고 완료를 기록한다. 동일하거나 누락된 집계, 다른 달, 인증 변경, 서버 대기와 중단은 완료로 인정하지 않는다. 같은 사이트의 별도 자동 입장은 보류하고 다른 사이트 작업은 진행한다. 집계는 계정 전체의 월간 수치이므로 동시에 다른 기기에서 생긴 증가까지 개별 강의와 연결할 수는 없다.

입장 직후 한 번 확인하고 필요하면 정상 수강에 걸릴 수 있는 시간을 기다린다. 검증용 페이지 로드는 정해진 횟수와 입장 기한 안에서만 수행하며 창을 최대 4분 유지할 수 있다. 집계가 늦거나 진위가 불명확하면 확인 필요로 기록한다. 인증된 회원 응답의 직접 재요청 계약을 입증할 수 없어서 브라우저가 원래 호출한 GET을 관찰한다. [출처와 초기 사이트 계약](PORTING_DIRECTION_V156.md)
