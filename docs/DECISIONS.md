# 확정한 결정

새 결정은 날짜·문제·선택·영향을 추가한다. 사용자의 후속 지시가 기존 결정에 우선한다.

| ID | 결정 | 유지할 이유와 영향 |
|---|---|---|
| D01 | Windows 우선의 독립 상주 프로그램 | PC가 켜져 있고 절전이 아닐 때 실행. 원격 조작·WOL·절전 해제 제외 |
| D02 | 운영 서버·유료 API·모바일 동기화 없음 | 각 기기에서 로그인·실행. 기기 간 중복은 사용자 안내로 처리 |
| D03 | Electron45 고정·원격 창 격리 | TLS·sandbox·contextIsolation 유지. 관리 IPC는 정확한 관리 창만 허용 |
| D04 | 개발자용과 배포용 분리 | 앱 ID·프로필·설정·잠금 분리. 공개 실행파일은 distribution만 |
| D05 | 실행 전 영속 기록·불확실 재전송 금지 | 재시작·업데이트로 시도 기록을 지우지 않음. 한미의 의도한5회는 별도 슬롯 |
| D06 | 계정은 별도 후보 로그인 검증 후 Windows DPAPI 저장 | 보호 저장소가 없으면 중지. 평문 대체·개인 브라우저 계정 가져오기 금지 |
| D07 | 사이트 원래 버튼·처리기와 완료 근거 사용 | 추측한 수령 API·보안 확인·시청시간 우회 제외 |
| D08 | 외부 자동 기능은 기본 꺼짐 | 기능별 선택과 전체 자동 실행 허용을 모두 요구 |
| D09 | 같은 실행 환경이면 수동 작은 패치 | 같은 에디션·정확한 이전 버전·모든 runtime 해시 대조. app 전체 교체 |
| D10 | 2026-10-26 PC 전용 공개 GitHub 공동작업·배포 결정 | 사용자가 소스 공개를 승인. doctor-glean-pc에서 소스와 distribution 릴리스를 함께 관리. 브랜치·PR·검증·STATUS 갱신으로 인계. developer 공유 범위는 후속 D11을 따름 |
| D11 | 2026-10-26 개발자 실행파일을 지정 collaborator에게 공유 | 배포용은 공개 릴리스, 개발자용은 같은 공개 PC 저장소의 Draft. Draft 열람은 관리자·쓰기 권한 collaborator에게 제한되며 해당 권한의 코드/릴리스 편집 범위를 함께 안내. 과거 개인 초안은 보존 |
| D12 | 2026-10-27 디톡스 닫힌 서버 프로필 메뉴 판독 | 공개 CSS의 정확한 로그아웃 요소·안전한 목적지/원래 함수 참조를 읽음. 후보는 실제 인증 응답·제출 ACK·보호 목록 재조회·로그인 충돌 없음도 필요. 메뉴/로그아웃/함수/접근자는 실행하지 않으며 다른 사이트에 일반화하지 않음 |

| D13 | 2026-10-27 예약 검증과 실행 근거 구분 | 읽기 전용 사전 검사는 별도 작업 창에서 수행하고 계정 복구·입장 클릭·재생·예약/제출 잠금 변경을 하지 않는다. 정시 작업은 검사를 중단하고 우선한다. PC 클릭·이동·영상 관찰·사이트 완료를 따로 표시하고 기존 완료를 모바일 또는 PC의 신규 제출로 추정하지 않는다. 개발자 세부 이력만 기존7일 동의·한도·로컬 저장을 따르며 자동 전송은 없다. 기존 파일 형식과 재시도 제한을 유지한다. |

| D14 | 2026-10-27 조회 범위 보존과 예정 예약 일괄 검사 | 현재 목록 판독을 전체 조회로 승격하지 않고 범위 미확정 빈 결과로 기존 강의를 지우지 않는다. 일괄 검사는 선택 사이트의 시작 전 예약만 최대40건·2분·읽기 전용으로 처리하고 정시 작업·중지에 양보한다. 한 사이트 조회와 사용자가 요청한 저장 계정 복구도 기존 허용 범위·시도 제한을 따른다. |

| D15 | 2026-10-27 사전 검사 준비 대기와 PC 한미 날짜 묶음 보완 | 사전 검사는 문서 로드 뒤 최대8초 재판독하며 계정 복구/클릭/재생을 하지 않는다. 한미 보완 클릭은 원래 판독의 대상/버튼/모호성 중단에만 사용하고 같은 그룹의 날짜·제목·시각, 원래 버튼, 기존5슬롯·영속 잠금을 유지한다. 블루팜 기간은 시작 날짜/시각만 대조하고 모호한 복수 일정·잘못된 종료는 중단한다. |

| D16 | 2026-10-27 조회·입장 판독의 동일 DOM 대조와 닥터빌 고정 진입점 통일 | 한미는 원래 조회기가 지원하는 제목 앞 클래스 없는 시각을 같은 날짜 묶음에서만 읽고, 블루팜은 연자·포인트와 분리된 최소 일시 필드를 대조한다. 원래 조회기와 PC 입장기를 같은 합성 화면에서 함께 검사한다. 닥터빌은 정상 수동 창과 같은 인코딩된 고정 URL로 진입하며 callback·경로·인증 근거를 완화하지 않는다. 실제 Windows SSO 원인은 별도 확인이다. |

개발 문서는 `CONTRIBUTING.md`, 제품 범위는 `DEVELOPMENT_POLICY.md`, 현재 근거와 우선순위는 `STATUS.md`가 기준이다. 과거 빌드의 통과 수를 현재 상태로 쓰지 않는다.
