# 확정한 결정

새 결정은 날짜·문제·선택·영향을 추가한다. 사용자의 후속 지시가 기존 결정에 우선한다.

| ID | 결정 | 유지할 이유와 영향 |
|---|---|---|
| D01 | Windows 우선의 독립 상주 프로그램 | PC가 켜져 있고 절전이 아닐 때 실행. 원격 조작·WOL·절전 해제 제외 |
| D02 | 운영 서버·유료 API·모바일 동기화 없음 | 각 기기에서 로그인·실행. 기기 간 중복은 사용자 안내로 처리 |
| D03 | Electron45 고정·원격 창 격리 | TLS·sandbox·contextIsolation 유지. 관리 IPC는 정확한 관리 창만 허용 |
| D04 | 개발자용과 배포용 분리 | 앱 ID·프로필·설정·잠금 분리. 공개 실행파일은 distribution만 |
| D05 | 실행 전 영속 기록·불확실 재전송 금지 | 재시작·업데이트로 시도 기록을 지우지 않음. 한미의 의도한5회는 별도 슬롯 |
| D06 | 계정은 별도 후보 로그인 검증 후 Windows DPAPI 저장 | 보호 저장소가 없으면 중지. 평문 대체·개인 브라우저 계정 가져오기 금지 |
| D07 | 사이트 원래 버튼·처리기와 완료 근거 사용 | 추측한 수령 API·보안 확인·시청시간 우회 제외 |
| D08 | 외부 자동 기능은 기본 꺼짐 | 기능별 선택과 전체 자동 실행 허용을 모두 요구 |
| D09 | 같은 실행 환경이면 수동 작은 패치 | 같은 에디션·정확한 이전 버전·모든 runtime 해시 대조. app 전체 교체 |
| D10 | 2026-10-26 PC 전용 공개 GitHub 공동작업·배포 결정 | 사용자가 소스 공개를 승인. doctor-glean-pc에서 소스와 distribution 릴리스를 함께 관리. 브랜치·PR·검증·STATUS 갱신으로 인계. developer 공유 범위는 후속 D11을 따름 |
| D11 | 2026-10-26 개발자 실행파일을 지정 collaborator에게 공유 | 배포용은 공개 릴리스, 개발자용은 같은 공개 PC 저장소의 Draft. Draft 열람은 관리자·쓰기 권한 collaborator에게 제한되며 해당 권한의 코드/릴리스 편집 범위를 함께 안내. 과거 개인 초안은 보존 |

개발 문서는 `CONTRIBUTING.md`, 제품 범위는 `DEVELOPMENT_POLICY.md`, 현재 근거와 우선순위는 `STATUS.md`가 기준이다. 과거 빌드의 통과 수를 현재 상태로 쓰지 않는다.
