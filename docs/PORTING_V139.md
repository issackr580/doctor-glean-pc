# 모바일 v139 기준 PC 이식

기준 PC는 main `7bdaf1b33c715eef2551b52f285395ef105f0137`, 실행판 preview.28이다. 실행 소스는 `36bd10d100bdbdc4ac4273b4125e16138d9c189f`다. 별도 `feat/mobile-v139-port` 작업본에서 preview.29를 개발한다. 첨부 참고 코드와 모바일의 검사 결과는 PC 구현 또는 Windows 성공의 증거로 사용하지 않는다. [기능별 조사표](PORTING_V139.json)에 변경 전 증거와 차이를 기록했다.

## 기존 구조와 보존

- Electron45.0.0 / Windows x64, Node24/npm11 개발 환경을 유지한다. Android Activity/Service/AlarmManager/Keystore/설치 코드를 가져오지 않는다.
- developer/distribution 앱 ID, 단일 실행 잠금, 데이터 폴더, 사이트별 persist partition v1, Windows DPAPI를 유지한다. 저장 계정·동의·조회 선택·기능 설정·예약·취소·시도 파일을 초기화하지 않는다.
- 기존 JSON은 같은 reader로 읽는다. 새 닥플 조회와 입장은 기존 선택 배열에 자동 추가하지 않는다. 새 `pc-options-v1.json`은 기존 일일 작업 선택을 보존하는 초기값과 메모·설문 제외·입장 서버 설정만 가진다. 계정 삭제는 명시적인 계정 삭제 조작에 한정한다.
- PC 사용자가 요청한 직접 로그인 개발자3초/배포10초, 자동60초·15분3회·하루10회와 거절/불확실 중단을 유지한다. 모바일의 일반 복구15분/일3회로 바꾸지 않는다.
- PC Ed25519 서명 피드·에디션/플랫폼/아키텍처·패치/전체 app/runtime 해시·설치 helper 백업/재시작/실패 복구를 유지한다. APK와 Android 서명은 후보가 아니다. 업데이트 서명을 Windows Authenticode라고 표현하지 않는다.

## 연결한 기능

10사이트 조회와 9사이트 입장 선택을 제공한다. 종근당은 조회·계정 복구만 지원한다. 새 엔진은 모바일 `197e53ea9c7e15db710be9caebe27869c591c061`의 v139 원본에서 기존 sync 스크립트로 생성했으며 세 manifest에 출처와 SHA를 기록한다. 개인 인계 ZIP·모바일 Java·원문 보고·APK·서명 자료를 PC 소스/실행물에 포함하지 않는다.

닥플은 관측된 C01/LIVE 목록의 전체 제목·독립된 전체 날짜/시작시각·공개 양수 ID·신청 상태를 보존한다. 원래 다음 페이지 버튼의 signature를 확인하며 로딩·알 수 없는 행·혼합 필터를 확인된 빈 목록으로 바꾸지 않는다. 신청 완료 LIVE만 `SHA-256('docple|'+날짜+'|'+ID)`로 예약한다. 같은 제목의 다른 ID는 별개이고 제목 변경은 새 소비 권한이 아니다. 시작30분 전~시작10분 후 창에서 목록의 관측 href→같은 ID 상세→독립 일정/신청 상태→원래 단일 활성 입장 버튼을 확인한다. 신청·동의·설문·다시보기는 자동 진행하지 않는다. 로그인 복귀 query는 로그인 신호로만 사용한다.

후다닥·디톡스는 시작부터10분 안의 첫 회차, 실제 같은 강의 플레이어 관찰을 기준으로10분/20분 뒤의 후속 회차를 구분한다. 이동·클릭만으로 후속 기준을 만들지 않는다. 한미의 시작 기준10분 간격5회/90초 창은 유지한다. 새 HMP 달력/그룹/영문 요일 판독과 메디게이트 복제 카드 판독은 v139 snapshot을 사용한다.

닥플과 일반 사이트의 확인된 원래/변경 시각은 최대 두 checkpoint로 저장하고 슬롯별 필수 시도를 구분한다. 같은 key 하나만 갱신하며 다른 강의를 지우지 않는다. 세 번째 시각으로 횟수를 늘리거나 취소·수동 입장·불확실한 외부 동작을 다시 허가하지 않는다. **닥터빌은 기존 D26의 새 상세 두 번 확인→최신 일정/타이머 수정→미입장 복구를 유지**한다. 모바일의 두 시각 소비 정책으로 이미 소비한 닥터빌 강의를 다시 클릭하도록 바꾸지 않는다.

출석/캡슐·브랜드관·퀴즈의 기능 스위치와 일일 작업 선택을 연결한다. 브랜드2는 브랜드1의 실제 성공 영수증을 요구한다. 닥터빌의 날짜별 시도와 별도로 퀴즈 ID별2회 상한/pending fuse를 `quiz-action-fuses-v1.json`에 저장한다. 서버 횟수 역행·pending·이미 완료는 거절한다. 인터엠디는 개시 전 상태의08:00 재확인과 직접 참여 안내이며 정답 자동 제출은 없다.

종근당의 자동 복구 동의를 확인한 당일 첫 조회는 `credential-action-fuses-v1.json`의 독립 lease를 먼저 저장한다. 필요하면 검토된 원래 로그아웃 처리기를 한 번만 호출하고 같은 문서의 준비/실제 자격 제출/인증 결과를 구분한다. 미제출 unavailable은 당일 lease를 갱신하지 않으며 일반 로그인 복구 quota와 별개다. 로그인 결과를 Bell 적립으로 표시하지 않는다. 기존 문서 세대/URL/로딩 guard 이전에는 자격 정보를 읽지 않는다.

키메디 라운지는00:01:03, 관측된6개(mask95)/7개(mask127) 구성만 처리한다. 대상 전체의 필수 시도를 먼저 저장한 뒤 한 JS batch를 보내고 응답 유실로 재claim하지 않는다. 오전08:10 작업은30분 허용 구간과 당일 영속 상태를 사용한다. PC 종료/절전 때 실행을 보장하지 않는다.

설문은 명시적인 기능 선택 뒤 원래 닥터빌 강의 ID에 연결한 읽기만 수행한다. 검토된 고정 읽기 경로와 실제 표시 countdown을 사용하며 답변을 제출하지 않는다. 미확인 상태의 탐색 구간은 시작+3시간, background 읽기는40회, 한 읽기는12초이며 정시 입장이 우선한다. 알림은 참여 가능/10분/5분 구간을 구분하고 제외 선택·완료·기존 기한을 보존한다. 새60분을 가정하거나 과거 기한을 연장하지 않는다. Windows 알림과 앱의 원래 설문 화면 열기를 연결한다.

메디게이트 외부 입장은 사용자가 선택한 정확 DNS host 최대16개와 host별 HTTP 허용만 사용한다. 입장 시도 저장 뒤 소유한 원래 창의 원래 GET/POST만 허용하며 차단 URL/POST를 보관·재생하지 않는다. 설정 변경은 차단된 요청을 다시 보내지 않는다. TLS·sandbox·Node 없음·다운로드 차단을 유지한다. 모바일 전용 외부 브라우저 인계 대신 기존 PC의 보호된 사이트 창을 사용한다.

날짜 메모·간략 목록 복사, 로그인 후 이전에 실패한 선택 작업의 상태 재확인, 설문 제외와 보고 미리보기/복사/TXT를 제공한다. 읽기 전용 대기열은 자동 수령 batch에 합치지 않는다. 미리 본 보고의 같은 바이트만 token 유효기간 안에서 복사·저장한다. 진단과 옵션 삭제/목록 갱신은 필수 시도·quiz fuse·일일 로그인 lease를 지우지 않는다.

## 검증 범위

`test/porting-v139.test.js`는 PC 저장소/스케줄러/중복 제한을, `scripts/electron-porting-cases.mjs`는 실제 Electron·합성 HTTPS·모바일과 별개인 PC host/저장/원래 DOM 버튼 경계를 검사한다. 기존 전체 Node·Electron 회귀도 유지한다. 새 브라우저 사례는 entry suite에 포함되므로 모바일 검사 수에 합산하지 않는다.

실제 Windows DPAPI·로그인 회원 DOM·원래 강의 입장·영상 진행·출석/보상, 절전/복귀·재부팅·알림 수신·실제 GitHub 로그인/업데이트 설치는 별도의 실기기 확인이다. 합성의 clicked, 허용 이동, 닥플 watch 문서 로드와 실제 재생/출석 인정은 서로 다른 결과다. v27 사용자가 보낸 과거 점심 성공 기록도 v29나 새 닥플 기능의 성공 증거가 아니다.
