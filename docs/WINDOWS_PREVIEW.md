# Windows 검증판 실행 안내

0.1.0-preview.28는 강의 조회·당일 작업·자동 입장·예약 실행을 연결한 검증판이다. Windows와 실제 사이트 계정에서의 확인은 남아 있다.

1. 첫 설치는 전체 ZIP을 풀고 개발자용 DoctorGlean-Developer.exe 또는 배포용 DoctorGlean.exe를 실행한다.
2. 사이트 열기에서 직접 로그인한 뒤 그 창 상단의 「로그인 마침 · 이 사이트 조회」를 누른다. 이 메뉴는 계정 저장과 별개로 이 앱의 전용 세션을 보관한다. 로그인된 근거와 세션 저장 요청 결과는 따로 표시한다.
3. 자동 실행에서 필요한 기능을 체크하고 **자동 실행 허용**을 누른다. 기능과 전체 허용은 처음에는 모두 꺼져 있다.
4. **오늘 한 번에 실행**은 출석·퀴즈 확인 후 오늘 강의를 조회하고 켜 둔 기능을 실행한다. **상태만 확인**은 제출 없이 읽는다.
5. 자동 입장 사이트를 선택하고 오늘 강의를 조회한다. 한미는 신청된 강의 시작부터 10분 간격 최대 5회이며 시작 10분 전 준비 확인은 별도다. 강의 종료를 확인하면 중단한다.
6. 오전 08:10과 평일 00:01:02 닥터라운지는 해당 옵션을 켠 뒤 다음 준비 시각부터 적용된다. PC·프로그램이 실행 중이어야 하며 절전이나 종료로 놓친 기한을 소급하지 않는다.

브랜드관 배너가 없으면 오늘 확인 종료이며 적립 완료는 아니다. 닥터빌 퀴즈는 오늘 퀴즈를 찾아 하루 1회 제출한다. 오답이나 결과 미확인은 자동 재제출하지 않는다. 인터엠디 퀴즈는 상태만 확인한다. 닥터라운지는 사이트에서 활성화된 실제 포인트 버튼만 누르며 선착순 성공을 보장하지 않는다.

수동 로그인 창을 사용 중인 사이트는 자동 작업이 건너뛴다. 다른 사이트의 창을 열어도 기존 조회를 취소하지 않는다. 로그인 마침 요청은 차례로 조회한다. 직접 입장 클릭을 감지하면 남은 자동 입장에서 제외한다. 감지하지 못했으면 **직접 입장했어요**로 기록한다. 실행하지 않은 예약은 원래 기한 안에서 **다시 예약**할 수 있다. 취소·실행·불확실 제출의 제한을 유지한다.

프로그램 하단의 **오류보고 저장**으로 버전·단계·시각·개수·고정 오류 코드를 내보낼 수 있다. 닥터라운지는 준비·페이지 준비·미션 판독·가능 버튼 발견·최초/최종 실행·종료 시각과 시도/전송/완료 개수를 포함한다. 개발자용에는 선택적인 7일 로컬 진단도 있다. 진단은 자동 전송하지 않고 계정·쿠키·URL·페이지 원문·정답은 제외한다.

지속 백그라운드 영상 재생은 추가하지 않았다. 비밀번호 저장·만료 복구는 아래 계정 메뉴에서 사용한다. 종근당 매일 강제 새 로그인은 별도 검증 단계다. 닥터빌 설문 자동 수행도 별도 검증 대상으로 남겨 두었다.

## 계정 저장과 복구

사이트 카드의 **계정 저장·복구**에서 아이디·비밀번호를 입력하고 **로그인 검증 후 저장**을 누른다. 임시 프로필에서 실제 로그인을 확인한 계정만 Windows DPAPI로 암호화해 저장한다. 보호 저장소를 쓸 수 없거나 추가 인증·로그인 실패·결과 미확인이면 저장하지 않는다. 기존 비밀번호를 화면에 다시 보여 주지 않는다.

자동 복구를 원하면 계정별 **자동 복구 허용**을 체크한다. 전체 자동 실행도 허용되어 있어야 한다. 실제 로그인 필요를 확인한 강의 조회·출석·입장·자정 작업에서 한 번 복구한다. 보안 확인은 우회하지 않는다. 비밀번호 거절·응답 불확실은 자동 재제출하지 않고, 최근 시도 간격·15분3회·당일10회 제한을 유지한다. 계정 교체로 횟수를 초기화하지 않는다.

**저장 계정으로 로그인**은 원래 작업 프로필에서 수동 복구한다. 수동 사이트 창을 사용하는 중이면 먼저 닫거나 로그인 마침을 누른다. **저장 계정 삭제**는 진행 중 복구를 중지하고 암호화된 계정을 삭제한다. 계정 창을 닫으면 입력값을 비우고 현재 계정 작업을 중지한다. 이미 전송된 로그인 요청을 취소했다고 표시하지 않는다.

계정 저장과 세션 저장은 별개다. 휴대폰·Chrome·Edge 쿠키를 복사하지 않고 개발자용/배포용도 서로 공유하지 않는다. 일반 설정·진단·배포물에는 계정값이나 비밀번호를 넣지 않는다. Windows DPAPI와 실제 사이트 계정 검증은 사용자 Windows에서 추가 확인할 단계다.

## 작은 패치

작은 패치는 목표 버전의 resources/app 전체를 교체한다. 릴리스에서 호환 검증한 같은 에디션의 이전 버전은 중간 패치를 차례로 적용할 필요 없이 바로 업데이트할 수 있다. 파일명과 manifest의 fromVersion은 비교 기준이며 호환 범위는 릴리스 안내를 확인한다. Electron 버전과 나머지 실행 환경 파일 해시가 모두 같아야 한다. 첫 설치·호환 미확인 버전·실행 환경 변경에는 전체 ZIP을 사용한다.

1. 관리 창 또는 트레이 메뉴에서 **프로그램 종료**를 누른다. X는 트레이 숨김이라 이전 프로세스가 남는다.
2. 패치 ZIP을 임시 폴더에 푼다.
3. 기존 실행파일 옆의 resources 안에서 app을 app-backup-이전버전 등으로 이름을 바꾼다.
4. 패치의 resources/app 전체를 기존 resources에 복사한다. 파일을 섞거나 app/app으로 중첩하지 않는다.
5. 같은 폴더의 기존 EXE를 직접 실행하고 하단 버전이 목표 버전인지 확인한다.

문제가 생기면 완전히 종료한 뒤 새 app을 다른 이름으로 옮기고 백업 폴더를 app으로 되돌린다. `%APPDATA%`의 로그인·설정·시도 기록 폴더는 교체하지 않는다. 올바른 위치는 resources/app/package.json이며 그 파일의 version도 확인할 수 있다.

배포용은 [공개 릴리스](https://github.com/issackr580/doctor-glean-pc/releases/tag/pc-v0.1.0-preview.28)에서 받는다. 개발자용은 관리자 또는 지정된 쓰기 권한 collaborator가 GitHub 로그인 후 같은 [Releases 목록](https://github.com/issackr580/doctor-glean-pc/releases)의 **PC 개발자용 0.1.0-preview.28 · 협업자 전용 Draft**에서 Assets를 연다. 초안의 임시 링크는 바뀔 수 있고 로그인하지 않으면 404가 정상이다.

두 에디션과 Android는 로그인·설정·실행 내역을 공유하지 않는다. 자동 실행 장비를 정해 사용한다. 프로그램은 별도 서버·유료 API·자체 원격 조작·절전 해제·상주 업데이트를 사용하지 않는다. 자체 Windows 코드 서명은 없다.

이번 계정 수정은 로그인 제출 후 페이지 이동을 기다린 뒤의 주소·문서로 확인해요. 허용된 인증 팝업도 같은 격리 프로필에서 확인하며, 비밀번호를 새 문서에 다시 제출하지 않아요. 제한에 걸리면 다음 가능 시각을 표시해요. 저장과 자동 복구를 허용한 경우 작업 프로필도 확인한 뒤 해당 사이트를 다시 조회해요. 이미 저장한 계정은 다시 입력하지 않고 저장 계정 로그인으로 확인할 수 있어요.
