## PC-016 — 일정 변경 반영과 진행 중 미입장 예약 복구

preview.27에 반영해 게시했다. 같은 키의 기존 예약을 건너뛰어 새 시각이 반영되지 않는 조건을 재현했다. 사용자의 우선 목표는 신청한 강의를 최대한 놓치지 않는 것이다. D26은 당일 닥터빌 일반 예약의 새 상세를 확인해 시각·실행 창·타이머를 함께 고치고, 옛 기한을 지났어도 현재 입장 가능한 미입장 강의를 복구한다.

최신 조회의 같은 날짜·완전 제목·단일 고정 상세 링크는 읽기 힌트다. 같은 링크의 캐시 시각 충돌이나 예약과 다른 시각만으로 중단하지 않는다. 새 상세의 독립 날짜·제목·첫 시작 시각을 두 번 대조해 실제 일정을 결정한다. 기존 상세 identity와 다른 ID·복수 식별 링크는 거절하고 legacy identity는 검증 뒤 연결한다. 확인된 미래 일정은 버튼이 아직 열리지 않아도 재예약한다.

외부 시도가 없었던 실패/expired 예약도 복구한다. 새 시작+10분 뒤에는 원래 입장 버튼의 ready와 명시적인 미래 종료시각이 모두 필요하며, 즉시 실행을 준비하고 새 기한은 현재+10분과 종료 중 이른 값이다. 실제 클릭에서도 현재 대상·버튼·종료시각과 영속 기록을 다시 확인한다. 취소·클릭/수동 입장·소비·불확실한 외부 시도는 복구하지 않는다. 기존 key·receipt·attempts·retries·필수 원장·한미 반복 슬롯은 유지한다.

## v19 수정과 게시

취소가 이미 완료된 상태에서도 시작한 load/evaluate의 뒤늦은 실패를 관찰한다. 원본 두 bounded 함수의 미처리 rejection 조건을 strict Node로 재현하고 공통 함수로 보완했다. 취소한 작업을 재개하거나 외부 제출을 다시 보내지 않는다. 실제 Windows 팝업의 정확한 오류명과 동일 원인은 미확정이다.
