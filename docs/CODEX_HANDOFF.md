## 변경과 검증

닥터빌은 기존 허용 호스트의 고정 seminarDetail 경로·단일 숫자 seminarId에서만 일반 제목 요소와 같은 작은 영역의 독립된 날짜·첫 시작시각을 함께 대조한다. 200요소/2000글자 안에서 요일·범위 끝 시각·제목/소개/프로필 날짜·다중 일정·중복 제목·추가 쿼리를 확인한다. 종료된 세미나입니다. 표식은 종료이고 신청취소 버튼은 기신청의 읽기 전용 근거이며 누르지 않는다. 미리보기 VOD 표식은 종료 증거가 아니다.

목록의 단일 관찰된 상세1회 읽기→기존 영속 기록→원래 입장 버튼 실행과 종료 시0클릭을 확인했다. 기존 기한·취소/소비 기록·한미5슬롯·불확실 재제출0회·v1 저장·DPAPI·에디션별 프로필·수동 창 보호를 유지한다. 신청·입장·플레이어 도착·영상 진행·출석/적립은 별도다.

verify:pc는 Node233·구문·실제 Linux Electron45/Xvfb 관리105·자동30·계정121·입장87·replay136(합성34시나리오)·신청193(46시나리오), Electron 전체672개를 현재 입력/결과 SHA로 확인했다. 빌드된 Windows resources/app는 Linux Electron에서 개발자105/배포91·같은 상위 appData의 에디션 분리를 확인했다. 깨끗한 소스171파일·의존성·Node233·구문 재현·22→23 동일 runtime 패치를 확인했다. 합성 통과는 실제 Windows·DPAPI·인증 사이트 성공이나 원래 실패 원인 확정이 아니다.

v22 명시적 수강 신청과 v21 회차별 선택 보고·PC 합성 재현·명시적 업데이트 확인은 유지한다. 배포용에는 개발자 추가 기록기·모듈·preload/IPC·화면을 넣지 않는다. 자동 설치·원격 규칙·진단 전송은 없다. [품질 흐름](QUALITY_WORKFLOW.md)을 따른다.

[수동 업로드](https://github.com/issackr580/doctor-glean-pc/actions/runs/40823807440) 뒤12개 자산을 재다운로드해 서버 SHA·체크섬·ZIP 내부 파일 전체를 검증하고 배포용만 공개했다. 개발자 Draft·독립 웹 공개/404 경계를 확인했고 완료한 임시 workflow를 제거한다. 자동 게시·예약 실행·공개 개발자 artifact는 남기지 않는다.

## 다음 확인과 경계

- [PC 검증](ENTRY_VALIDATION.md)에 따라 Windows에서 닥터빌 실제 상세 대상·원래 입장 버튼·정확한 플레이어·영상/적립을 따로 확인한다. 인증 DOM 없이 실제 사이트 성공을 확정하지 않는다.
- PC 전용 강의의 외부 플레이어 계정 생성·개인정보 동의·추가 인증은 사용자가 사이트에서 직접 마친다. 사이트/팝업 허용 범위를 넓히거나 추가 인증·보안·시청시간·적립 조건을 우회하지 않는다.
- 닥터빌의 로그인 복구 후 작업 프로필 인증 유지·목록의 제목/날짜 미일치는 실계정의 추가 확인 대상이다. 이번 상세 보완만으로 이 원인이 해결됐다고 확대하지 않는다.

- vendor v113이다. 모바일 소스·APK·서명·릴리스는 변경하지 않았고 모바일 검증을 PC 성공으로 대체하지 않는다. 종근당 새 로그인·설문·지속 재생·추가 사이트 반복 입장은 별도 범위다.
