## 변경과 검증

PC-016/D26은 당일 닥터빌의 미시도/미소비 예약을 새 상세로 확인해 실제 일정으로 갱신한다. 캐시와 예약 시각이 달라도 같은 상세의 독립 날짜·완전 제목·첫 시작 시각을 두 번 확인해 time/start/due/deadline/nextAt을 원자적으로 수정한다. 서로 다른 상세 ID는 거절하며 legacy identity는 검증 뒤 연결한다. 미래 일정은 not_open도 재예약한다.

옛 기한을 지난 실패/expired도 현재 입장 가능하면 복구한다. 진행 중 강의는 ready를 요구하며 새 시작+10분 뒤에는 명시적인 미래 종료시각도 확인한다. 즉시 실행을 준비하고 새 기한은 현재+10분과 종료 중 이른 값이다. 실제 입장도 새 대상·첫 시작/종료·원래 버튼과 영속 시도를 확인한다. 취소·클릭/수동 입장·소비·불확실은 재제출하지 않는다. 기존 key·receipt·attempts·retries·필수 원장·한미5슬롯을 보존한다.

일정 확인은 고정 main→관찰 단일 상세 GET의 읽기이며 계정 복구·입장/신청 클릭·팝업/재생·필수 시도 소비가 없다. 후보40개·진행 중 우선·다른 정시 작업 양보·중지/문서/조회/날짜 변경 무효화·저장 실패0클릭을 유지한다. 새 폴링·IPC·origin·자동 전송은 없다. v1의 선택적인 identity·최근8개 변경/복구 이력·종료시각은 실제 v26 reader도 보존한다. 일반 진단에는 원문 URL/ID/identity가 없다. 개발자 schedule_updated는 prepare 읽기이며 실제 입장 버전/시도로 소급하지 않는다. 기존7일 동의·한도·배포용 분리를 유지한다.
