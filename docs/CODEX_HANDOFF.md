## 마지막 수정과 검증

v13은 디톡스 달력 확인·현재 목록·추가 목록 수를 제한된 사실로 저장·내보내기까지 보존한다. 현재 목록 확인을 전체 조회로 승격하지 않고 최종 연결 실패·취소·시간초과·정시 양보를 우선 표시한다. 범위 미확정 빈 결과로 기존 강의를 지우지 않으며 복사 일정표에도 확인 범위를 표시한다.

사이트 한 곳 재조회·명시적인 저장 계정 로그인을 제공한다. 기존 실패 뒤 자동 재시도 중단·최근/당일 제한·거절 잠금은 유지한다. 예정 예약 일괄 사전 검사는 오늘의 선택된 입장 사이트·시작 전 예약을 최대40건·2분간 순차 판독한다. 계정 복구·입장 클릭·재생·예약/제출 잠금 변경은 없으며 정시 작업·중지에 양보한다. 처리·건너뜀·중단과 예약별 결과를 표시하고 프로그램 시작 전/후 클릭을 구분한다. 배포용에는 개발자 추가 기록기가 없다.

Node166·구문, 실제 Linux Electron45/Xvfb 합성 HTTPS 관리 창70·자동 작업28·계정90·PC 입장24, 최종 Windows 묶음 관리 창 개발자70/배포64를 확인했다. 같은 appData 상위 경로의 에디션 분리, 깨끗한 소스145파일 재현, 12→13 동일 runtime 패치를 확인했다. 초기 관리 창의 잘못된 합성 과거 이력 fixture는 저장 검증에서 중단됐고 수정 뒤 새 완료 표식·70항목을 확인했다. Electron 실행기도 완료 표식이 없는 종료를 통과하지 않는다.

[수동 업로드 실행](https://github.com/issackr580/doctor-glean-pc/actions/runs/40462379382)은 고정 소스·검증본 전체 파일 해시·기존 v12 자산 SHA를 대조해 기존 Draft에만 업로드했다. 모든 자산을 다시 내려받아 서버 SHA·체크섬·ZIP 내부 파일 전체를 확인한 뒤 배포용만 별도로 공개했다. 개발자용은 Draft이며 독립 웹 조회로 공개/404 경계를 확인했다. 완료한 일회성 workflow는 제거했고 예약·자동 게시·공개 개발자 artifact는 없다. 과거 릴리스·자산은 변경하지 않았다.
