## 마지막 수정과 검증

사용자의 긴 대기 개선 요청에 따라 직접 로그인 제출을 개발자3초·배포10초 간격으로 분리했다. 직접 요청에는 자동 복구15분3회 제한을 적용하지 않는다. 사이트별 하루10회, 자동60초·15분3회·거절/불확실 뒤 자동 재제출 중단은 유지한다. 대기/당일 한도 중에도 현재 세션은 읽되 실제 비밀번호 전달 전 영속 reserve에서 제한을 다시 확인한다. 후보 저장·수동 창 보호·DPAPI는 유지하고 직접/자동 가능 시각을 구분한다.

닥터빌은 callback 없는 정확한 제공자 origin의 비동기 이동을 최대20회×400ms 수동 관찰한다. 이 대기는 입력·스크립트 실행·클릭·추가 GET/POST를 하지 않고 기존 기한을 늘리지 않는다. 후보/변형 callback/외부 origin을 제외하며 허용 화면의 URL·문서에서 두 준비 판독을 새로 시작한다. 입력/이동 허용 정책은 유지한다. providerPath 고정 enum과 providerSettling만 추가하고 토큰/주소 값은 기록하지 않는다.

v1 계정/시도 형식과 한도 판단에 필요한 현재 날짜10개·최근 rolling3개를 포함한 최대13개를 유지한다. 실제 v17 reader/writer의 읽기/다시 저장·당일 한도 호환을 확인했다. v17의 날짜/중복/블루팜 보완과 영속 제출·기한·한미5슬롯은 유지한다.

v17 원본의 긴 직접 대기·비동기 이동 조기 실패를 Node/실제 Electron에서 재현한 뒤 Node190·구문, 실제 Linux Electron45/Xvfb 합성 HTTPS 관리 창72·자동 작업28·계정103·입장54를 확인했다. 최종 Windows 묶음 관리 창 개발자72/배포66·같은 appData 상위 경로의 에디션 분리, 깨끗한 소스151파일 재현·17→18 동일 runtime 패치를 확인했다. [수동 업로드](https://github.com/issackr580/doctor-glean-pc/actions/runs/40520597729)는 고정 소스·검증본 전체 파일 해시·기존 v17 SHA를 대조해 기존 두 Draft에만 업로드했다. 모든 자산을 다시 다운로드해 서버 SHA·체크섬·ZIP 내부 파일 전체를 검증한 뒤 배포용만 공개했다. 개발자용은 Draft이고 독립 웹 조회로 공개/404 경계를 확인했다. 완료한 임시 workflow는 제거했고 자동 게시·예약 실행·공개 개발자 artifact는 없다. 과거 릴리스·자산은 변경하지 않았다.

## 실제 Windows 보고와 다음 작업

1. 추가 TXT/JSON은 v17 소스38e10e9·22:38 시작·22:43 내보내기이며 내보낸 시각 외 현재 상태가 같다. 닥터빌은229ms·판독0·제출0·policy_rejected·providerPath=other/callbackState=missing이다. 기본 경로 복구는 호출되지 않았고 정확한 다른 경로는 기존 enum으로 특정하지 못한다. 사용자는 직접 엠써클 로그인 뒤 자연스럽게 닥터빌 메인과 팝업까지 열린다고 확인했다. v18에서 providerSettling·새 경로 enum과 실제 인증 근거를 함께 확인한다.
2. 다른6사이트의 이번 복구에서는 인증을 확인했고 디톡스1·키메디2 강의를 읽었다. 입장16건은 이전 보고와 같고 새 검사/클릭은 없다. v15 배포용의 한미3회·인터엠디1회 클릭/이동, 개발자 종료/재시작에 따른 저녁 만료와 구분한다. 영상/적립과 미참여일 새 출석·퀴즈는 미확인이다.
3. [PC 검증 방법](ENTRY_VALIDATION.md)으로 실제 시각/버전·클릭·이동·영상·사이트 완료를 나눈다. Windows의 실제 제공자 경로·v18 자동 복구와 일정 DOM/메디게이트 식별·정시 입장·영상/적립을 재확인한다. 수동 로그인으로 얻은 세션과 PC 신규 제출을 합치지 않는다. 기존 시도 파일을 지우거나 불확실한 자동 요청을 반복하지 않는다.
4. vendor는 v113이며 모바일 v114 닥터라운지6/7·20초 분산은 미이식이다. mission_changed·제출0, 종근당 새 로그인·설문·지속 재생의 미확인 범위를 유지한다.

모바일 소스·APK·서명·릴리스는 수정하지 않는다. 에디션별 앱 ID·프로필·DPAPI·기존 외부 시도·원격 창 격리를 유지한다. 패치는 같은 에디션 preview.17에만 적용하며 트레이 완전 종료→app 백업→resources/app 전체 교체→하단 버전 확인 순서다. X는 숨기기다.
