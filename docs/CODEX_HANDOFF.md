## 마지막 수정과 검증

v12는 예약 수와 PC 실행·이동·영상 관찰·사이트 완료를 나눠 표시하고 제출 없는 예약 사전 검사와 완료 캐시도 새로 읽는 상태 확인을 추가했다. 사전 검사는 별도 읽기 전용 창을 쓰고 계정 복구·클릭·재생·실행 시도 잠금을 만들지 않으며 정시 작업에 양보한다. 개발자 동의 이력에는 자동 작업의 예약·판독·재시도·제출 전 기록·결과와 실행 버전/시각을 제한된 사실로 남긴다. 과거 결과의 실행 버전을 현재 버전으로 소급하지 않으며 배포용에는 추가 기록기를 넣지 않는다.

PC 입장 보완 판독은 원래 판독이 대상/버튼/모호성으로 멈춘 경우에만 같은 카드의 보이는 제목·날짜·시작 시각을 확인한다. 관찰된 동일 강의 식별자·상태가 모두 같을 때만 중복을 합친다. 다른 대상·미신청·보안 확인은 중단하고 기존 영속 잠금 뒤 원래 버튼을 사용한다. 실제 사용자 인증 화면의 정확한 DOM 원인은 미확정이다.

Node155·구문 검사, 실제 Linux Electron45/Xvfb 합성 HTTPS 관리 창65·자동 작업28·계정90·PC 입장24, 최종 Windows 묶음 관리 창 개발자65/배포59가 통과했다. 같은 appData 상위 경로의 에디션 분리, 깨끗한 소스144파일 재현, 11→12 패치의 동일 runtime을 확인했다. [수동 업로드 실행](https://github.com/issackr580/doctor-glean-pc/actions/runs/40458040865) 후 전체/패치/소스 ZIP을 다시 내려받아 서버 SHA·체크섬·모든 내부 파일을 로컬 검증본과 대조했다. 배포용만 별도로 공개했고 개발자용은 Draft다. 독립 웹 조회로 배포용 공개·개발자용404를 확인했다. 일회성 workflow는 제거했으며 자동 게시·예약 실행·공개 개발자 artifact는 없다.

Windows 사용자 v11 보고에서 디톡스는 로그인 POST1회·302 뒤 보호 목록 재확인·인증 근거와 새 목록 조회가 관찰됐다. 한미 PC 클릭·이동5회는 영상/적립 성공을 뜻하지 않는다. 닥터빌 날짜/시간 대조 실패, 메디게이트 중복, 키메디 버튼 부재와 별도 v10 사용자의 미신청은 구분한다. 당일 출석·퀴즈의 기존 완료 판독으로 PC 신규 제출이나 모바일 기여를 단정하지 않는다. 개인 원본은 저장소에 없다.
