## 마지막 수정과 검증

제목의 모든 지원 heading을 날짜 판독에서 제외하는 경계 조건을 추가했다. 닥터빌은 조회기가 읽은 카드 사이 일반 텍스트 날짜와 전용 시작 시각을 대조한다. callback 없는 제공자 기본 `/`·`/login`만 비밀번호 없는 전용 읽기로 분류하며 보안/추가 인증/정보 보완/비밀번호 폼이면 중단한다. 저장 계정 제출 전에만 고정 PC 페이지1회 GET으로 원래 흐름을 재확인한다. 후보·제출 후·다른 경로·변형 callback은 제외하고 허용 로그인/제출 정책·인증 근거·두 준비 판독·영속 시도 제한은 유지한다.

메디게이트는 같은 관찰 상세 링크/신청 상태인 읽기 전용 중복과 단일 입장 카드만 연결한다. 다른/없는 식별·신청/종료 차이는 계속 모호성 중단이다. 블루팜 보완을 정시 판독/원래 버튼 클릭까지 연결하고 같은 날짜/시각·진행 중 표시·제출 전 기록·불확실 재전송 금지를 유지한다. 선택적 inspection은 값 없는 날짜/시각·식별 개수와 읽기 전용 여부만 보존한다. 기존 receipt·시도 형식은 유지하고 실제 v15 reader의 되돌려 읽기/저장 호환을 확인했다.

v15 원본의 두 실패를 재현한 뒤 Node181·구문, 실제 Linux Electron45/Xvfb 합성 HTTPS 관리 창71·자동 작업28·계정97·입장54을 확인했다. 최종 Windows 묶음 관리 창 개발자71/배포65·같은 appData 상위 경로의 에디션 분리, 깨끗한 소스150파일 재현·16→17 동일 runtime 패치를 확인했다. [수동 업로드](https://github.com/issackr580/doctor-glean-pc/actions/runs/40511855754)는 고정 소스·검증본 전체 파일 해시·기존 v16 SHA를 대조해 기존 두 Draft에만 업로드했다. 모든 자산을 다시 다운로드해 서버 SHA·체크섬·ZIP 내부 파일 전체를 검증한 뒤 배포용만 공개했다. 개발자용은 Draft이고 독립 웹 조회로 공개/404 경계를 확인했다. 완료한 임시 workflow는 제거했고 자동 게시·예약 실행·공개 개발자 artifact는 없다. 과거 릴리스·자산은 변경하지 않았다.

## 실제 Windows 보고와 다음 작업

1. 추가 v15 배포용 보고는17:33 시작·21:03 내보내기다. 한미18:20/30/40의3회·인터엠디18:30:31의1회 클릭/이동을 확인했다. 한미 앞2슬롯은 기록이 없고 영상 inaccessible·적립 미확인이다. 닥터빌 저녁5건은 제목1~4·일정0, 메디게이트19:00은 대상2개로 미클릭이다. 키메디/블루팜 저녁 예약은 해당 배포용 스냅샷에 없다.
2. 개발자 보고는21:04 시작·21:18 내보내기이며 기록기의17:32 종료·21:04 재시작 때문에 저녁 예약10건이 재시작 시 만료됐다. 과거 한미 점심5회나 이 만료를 배포용 v15 실행 결과와 합치지 않는다. 닥터빌 배포용17:34 복구는 POST200·로그아웃 근거로 성공했지만 개발자21:18은221ms·판독0·제출0·providerPath=other/callbackState=missing의 정책 거절이다.
3. 기존 enum으로 개발자 제공자의 정확한 다른 경로를 알 수 없다. v17의 기본 경로 조건이 실제 해당 경로인지, 강의 DOM·메디게이트 식별과 Windows 로그인·정시 입장·영상·적립을 재확인한다. 진단 inspection의 날짜/시각/식별 개수와 readOnly·시각을 함께 본다. [PC 검증 방법](ENTRY_VALIDATION.md)을 따르고 기존 시도 파일을 지우거나 불확실한 제출을 반복하지 않는다.
4. 후다닥·디톡스·키메디는 두 에디션의 이번 복구에서 인증을 확인했다. 출석/퀴즈 완료는 기존 완료 판독으로 새 PC 제출·모바일 기여의 근거가 아니다. vendor는 v113이며 모바일 v114 닥터라운지6/7·20초 분산은 미이식이다. mission_changed·제출0과 종근당 새 로그인·설문·지속 재생의 미확인 범위를 유지한다.

모바일 소스·APK·서명·릴리스는 수정하지 않는다. 에디션별 앱 ID·프로필·DPAPI·기존 시도·원격 창 격리를 유지한다. 패치는 같은 에디션 preview.16에만 적용하며 트레이 완전 종료→app 백업→resources/app 전체 교체→하단 버전 확인 순서다. X는 숨기기다.
