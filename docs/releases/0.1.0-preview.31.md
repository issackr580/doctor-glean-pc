# PC 0.1.0-preview.31 — 공식 강의 ID와 기존 예약 보존

실제 preview.30 원본에서 닥터빌·키메디·메디게이트·후다닥·닥플·한미의 관측된 site+namespace+공식 ID를 수집→예약→목록/상세→입장 직전으로 연결한다. 같은 ID는 제목 변경을 허용하고 같은 제목의 다른 ID는 분리한다. 날짜/회차·시작·등록/종료·버튼·로그인/보안·원래 기한은 별도로 검사한다. [사전 조사/지원 화면/저장 호환](../PORTING_ID_V148.md)과 [수용표](../PORTING_ID_V148_ACCEPTANCE.json)를 따른다.

기존 단일 key에만 별칭을 붙인다. 실행/로그 참조·시도/취소/수동/unknown·회차/일정/receipt는 유지한다. 중복 옛 key는 새 조회 전 재시작에도 막고, 필수 기록을 원자적으로 저장한 뒤 같은 worker·계정/선택 epoch·격리된 문서 nonce·원래 카드/버튼을 다시 확인한다. 저장 실패0클릭·불확실 재전송0회를 유지한다. 원래 관측 링크/버튼만 사용하며 ID로 player URL을 만들지 않는다. HMP goDetail은 보이는 단일 숫자 리터럴만 읽고 실행하지 않는다.

기존 PC 계정/DPAPI·선택·사이트/에디션 세션·반복/일정 보정·서명/업데이터를 유지한다. 첫 시작 때 같은 에디션 로컬 상태를 복구 전 불투명 백업하며 외부로 보내거나 자동 복원하지 않는다. rollback 때 더 새로운 소비 기록을 보존한다. 인터엠디·블루팜·디톡스는 legacy다. 기존 PC에 없던 장기 시청/월간 집계/native 집계 재시도 proof를 완료로 표시하지 않는다.

합성46계약(320항목)은 실제 PC 정책 어댑터를 호출한다. 모바일과 다른 기존 PC legacy 키는 유지하고 reference DTO의 새 ID 없는 표현에 한정한 투영을 pcKey와 함께 공개한다. 추가 저장/경쟁/재시작/늦은 callback·실제6수집기/입장 번들·trusted 수동 통지를 검사한다. 전체 고정 입력·Windows 묶음/에디션·소스·패치·서명/서버 자산 결과는 게시 인계에서 별도 기록한다.

Linux Electron 합성 HTTPS 성공은 실제 Windows/DPAPI·실계정 로그인·회원 DOM·입장/시청/출석/보상·알림/절전/재부팅·사용자 버튼 설치 성공을 뜻하지 않는다. PC Ed25519 업데이트 서명은 Windows Authenticode와 별개다. 개인 원문/인증/키와 Android UI/서비스/Keystore/암호문·APK를 포함하지 않는다.
