# PC 0.1.0-preview.41

**설정·도움말 → 닥터빌 설문**에서 공용 개시 모드와 마감 알림을 설정한다. 개시 확인의 강의별 한도는 1·3·5·8회다. 마감 알림은 별도 선택이며, 카운트다운에서 확인한 마감 약 10분 전에 한 번 읽고 미완료 설문이 열려 있을 때 알린다. 설문 참여와 제출은 원래 사이트에서 직접 진행한다.

같은 에디션 preview.20~40은 작은 패치로 바로 올릴 수 있다. preview.40에서는 앱의 **설정·도움말 → PC 업데이트 확인**을 사용한다. 첫 설치에는 Windows x64 전체 ZIP을 사용한다.

고정 소스는 `c53d64c11c9273020d81d2ad4f966a31d35e5b26`이며 태그는 `pc-source-v0.1.0-preview.41`이다. Node 503개 및 Linux Electron 45 합성 HTTPS 1,634개를 통과했다. 설문 전용 175개가 포함된다. Windows 묶음의 관리 화면은 Linux Electron에서 개발자용 165개와 배포용 151개를 확인했다. 한국 자정을 넘는 한미 +25분과 00:00 및 00:01과 겹친 대조 사례는 합성 검사 시각에 영향을 받았다. 동일한 소스로 00:01을 지난 뒤 입장 검사를 다시 통과했다. Windows 실기기 알림·설치·실계정 통신량은 확인이 남았다.

서버 자산 12개를 다시 받아 크기·SHA-256·체크섬·ZIP 파일 전체를 확인했다. 게시된 preview.40의 실행 환경과 서버 패치를 대조했고, 기존 공개키로 두 에디션 피드와 같은 에디션의 버전 선택 42건을 확인했다. [수동 GitHub Actions](https://github.com/issackr580/doctor-glean-pc/actions/runs/45639129038)
