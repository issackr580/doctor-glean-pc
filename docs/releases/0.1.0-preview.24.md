# PC 0.1.0-preview.24 — 닥터빌 목록 날짜 묶음

날짜를 카드마다 반복하지 않는 목록에서 수집기는 제목/시각을 찾지만 기존 입장 사전 검사는 날짜를 찾지 못하는 조건을 합성 HTTPS로 재현했다. 같은 두 열 묶음의 날짜를 오른쪽 각 강의의 제목·전용 시작시각과 함께 확인한다. 날짜 열이 빈 행은 같은 부모의 바로 앞 동일 구조 단일 카드 행에서만 날짜를 이어받는다. 전체 문서의 마지막 날짜를 입장 근거로 빌리지 않는다.

숨긴/무관한 행·영역 경계·잘못된 요일·다른 날짜·카드와 묶음의 날짜 충돌·중복 대상·시작 필드 누락/복수/불일치는 거절한다. 클릭 직전의 날짜 변경은0클릭이며 정상 대상은 기존 제출 전 영속 기록 이후 원래 입장 처리기만 한 번 실행한다. 읽기 전용 사전 검사·신청 상태 확인과 기존 기한/취소/소비 기록·한미5슬롯·v1 저장·DPAPI·프로필·사이트/IPC 허용 범위를 유지한다.

개발자 회차의 inspect에는 날짜/시각 판독 실패 종류별 고정 개수만 추가한다. 원문 날짜·제목·HTML은 수집하지 않으며 receipt/inspection 형식은 바꾸지 않는다. 사전 검사 문구는 제목 후보 발견과 미발견을 구분한다. 캡처에서 관찰한 배치는 실제 인증 DOM의 클래스나 정확한 원인 확정이 아니다.
