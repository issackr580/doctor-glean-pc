# PC 0.1.0-preview.42

오류보고에 한국 날짜 기준 오늘과 전날의 사이트별 조회·입장·출석·퀴즈·설문 결과를 포함한다. 설문 설정과 닥터라운지의 개시 후 판독 사유, 문서 로드·읽기 횟수도 확인할 수 있다.

preview.40과 preview.41은 **설정·도움말 → PC 업데이트 확인**에서 올린다. 같은 에디션 preview.20~41은 작은 패치로 바로 올릴 수 있다. 첫 설치는 Windows x64 전체 ZIP을 사용한다.

고정 소스는 `a196d2bd0e5eda6a6d44ccee5e9330a31e875dae`이며 태그는 `pc-source-v0.1.0-preview.42`이다. Node 504개와 구문, Linux Electron 45 합성 HTTPS 1,636개가 통과했다. Windows 묶음의 관리 화면은 Linux Electron에서 배포용 153개·개발자용 167개를 통과했다. 처음 병렬로 실행한 패키지 검사에서 합성 이관 자료가 같은 경로를 사용해 충돌했다. 같은 상위 경로를 사용해 순서대로 다시 검사했으며 두 에디션의 데이터 경로를 확인했다. 초기 닥터빌 입장 합성 검사는 같은 소스로 재실행해 통과했다. Windows 실기기 진단 수집과 설치는 확인이 남았다.

서버 자산 12개의 크기·SHA-256·체크섬·ZIP 전체 파일을 대조했다. 게시된 preview.41의 실행 환경과 두 패치를 비교하고 기존 공개키로 서명 피드와 버전 선택 44건을 확인했다. [수동 GitHub Actions](https://github.com/issackr580/doctor-glean-pc/actions/runs/45997679758)
