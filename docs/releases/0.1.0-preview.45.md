# PC 0.1.0-preview.45

개발자용 업데이트는 저장된 GitHub 전용 세션을 먼저 확인한다. 인증이 필요한 경우 로그인 창을 한 번 연다. 평소 브라우저에서 받은 공식 작은 패치 ZIP은 개발자용 설정의 **받아 둔 패치 ZIP 설치**에서 선택한다. 앱은 서명 피드와 현재 실행 환경을 확인하고 설치·백업·재시작을 처리한다. 파일을 받고 나서 수동으로 압축을 풀거나 app 폴더를 교체할 필요는 없다. 개발자용에만 이 파일 선택기를 제공한다.

구버전에서 내장 GitHub 연결이 실패하면, 협업자 전용 Draft에서 이번 버전의 전체 ZIP을 받아 새 폴더에 푼 뒤 트레이에서 기존 앱을 종료하고 새 실행파일을 시작한다. 같은 에디션의 계정·설정·예약·시도 기록을 이어 쓴다. 같은 에디션의 preview.20~44에서 적용할 수 있는 app 패치를 제공한다. preview.44의 실제 배포 ZIP과 새 패치의 실행 환경을 파일별로 대조하고 기존 서명 피드의 호환 범위를 이어받았다.

고정 실행 소스는 `fe87e26a697168dc69dd43a88283827cef3b1ba7`이며 태그는 `pc-source-v0.1.0-preview.45`이다. Node 510개와 구문, Linux Electron 합성 HTTPS 1645개와 Windows 묶음의 Linux 관리 화면 배포용 159개·개발자용 173개가 통과했다. 합성 업데이트 28개에서 GitHub 기존 세션 재사용, 로그인 한 번, 서명된 패치 선택과 에디션 분리 및 기존 도우미의 재시작 경계를 확인했다. 실제 Windows 설치와 계정 인증은 별도 확인이다.

두 에디션의 서버 자산 12개를 받아 크기·SHA-256·체크섬·ZIP 파일 목록을 대조했다. 두 에디션의 패치로 서명된 업데이트 피드를 갱신했다. [수동 GitHub Actions](https://github.com/issackr580/doctor-glean-pc/actions/runs/46124382519)
