# PC 0.1.0-preview.40

첫 화면에서 오늘 강의를 한국 날짜와 시작 시각 기준으로 표시한다. 같은 시각의 강의는 한 묶음이다. 날짜 선택·조회·복사는 일정 화면에서, 자동 실행·계정·설정은 각 탭에서 관리한다.

같은 에디션 preview.20~39는 작은 패치로 바로 업데이트할 수 있다. preview.28~39에서는 기존 화면 하단의 앱 업데이트를 사용한다. preview.40의 업데이트와 오류보고는 **설정·도움말**에 있다. 첫 설치는 전체 Windows x64 ZIP을 풀어 실행한다.

고정 소스는 `562378713e10014cdc7850535b5a1bee5e46e6b4`이며 태그는 `pc-source-v0.1.0-preview.40`이다. Node 466개·구문 검사와 Linux Electron 45 합성 HTTPS 1,456개를 통과했다. Windows 묶음의 관리 창을 Linux Electron에서 실행해 개발자용 162개와 배포용 148개를 통과했다. 두 에디션은 같은 상위 경로 아래 서로 다른 앱 데이터 폴더를 사용했다. Windows 실기기 표시·설치·실계정 동작은 확인이 남았다.

수동 GitHub Actions에서 두 에디션을 Draft에 첨부했다. 서버 자산 12개를 재다운로드해 SHA-256·크기·체크섬·ZIP 전체 파일을 대조했다. 기존 공개키로 피드 서명을 확인했다. 같은 에디션·런타임의 버전 선택 40건에서 서버 패치의 전체 파일을 검증했다. [수동 GitHub Actions](https://github.com/issackr580/doctor-glean-pc/actions/runs/45380311006)
