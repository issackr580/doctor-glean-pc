# PC 0.1.0-preview.21 — 회차 진단·재현·검증 흐름

개발자용의 기존7일 동의·하루2000개·파일4MiB 한도 안에서 입장/준비/사전 검사 회차의 관찰 경과를 연결한다. 선택한 사이트·슬롯만 가림 처리한 보고서를 미리보고 동일한 내용으로 저장/복사한다. 진단 실패·삭제·철회는 계정/예약/시도 소비와 독립적이며 옛 진단 콜백과 미리보기 token을 차단한다. 클릭 요청·로컬 응답·허용 문서 이동·영상 관측을 실제 도착/적립 성공으로 확대하지 않는다.

새 PC 합성17종×360/1240 화면 폭의 replay를 추가하고 verify:pc가 전체 Node·구문·실제 Electron5종을 현재 입력/결과 SHA로 연결한다. 실패·skip·부분 결과·이전 JSON·검사 중 소스 변경은 전체 완료로 쓰지 않는다. Windows/실계정/패키지/게시 검증은 별도다.

사용자가 누르는 PC 업데이트 확인은 고정 PC 저장소 공개 메타데이터만 읽고 Windows x64·배포용·현재 채널·정확한 태그/첨부·상태·크기·SHA·출처를 대조한다. 조회 실패/범위 미완료는 최신 판정이 아니다. 기존 PC 검증판은 preview 채널이고 개발자용은 협업자 Draft 안내다. 자동 다운로드·설치·원격 코드/규칙·진단 전송은 없다. 자체 Windows 코드 서명은 새로 추가하지 않는다.

사이트 판독·실제 제출 기준·DPAPI·에디션별 프로필·기한·한미5슬롯·v1 시도/예약 형식과 vendor v113을 유지한다. 모바일 소스·APK·서명·릴리스와 과거 PC 실행물은 변경하지 않는다. 인증된 실제 사이트 입장·Windows DPAPI·영상/적립 성공은 별도 재확인이다.

검증 결과와 게시 근거는 완료한 소스·실행 환경에 맞춰 기록한다. 개인 전달 자료·원본 보고·실사용 활동은 공개 기록에 포함하지 않는다.
