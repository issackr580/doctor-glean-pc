# 0.1.0-preview.16 — 제공자 세션 재확인과 정시 입장 연결

2026-10-27. 배포용 공개 prerelease와 개발자용 협업자 전용 Draft 게시를 확인했다. 후속 경계 조건은 v17에서 보완한다.

## 실제 v15 Windows 보고

배포용 TXT는17:33 시작·21:03 내보내기, 개발자 TXT/JSON은21:04 시작·21:18 내보내기다. 개발자 두 파일은 내보낸 시각 외 현재 상태가 같다. 두 에디션의 프로필·시도·실행 시점을 합치지 않는다. 개발자 기록기는17:32 종료·21:04 재시작을 확인하며, 저녁 예약10건의 재시작 만료는 실제 입장 실행과 다르다.

배포용 한미는18:20/30/40의3회, 인터엠디는18:30:31의1회 클릭·허용 페이지 이동을 확인했다. 한미 앞2슬롯 기록은 없고 영상 inaccessible·적립 미확인이다. unknown 잠금은 실패 횟수가 아니라 재제출 제한이다. 닥터빌 저녁5건은 제목1~4·일정0으로 미클릭, 메디게이트19:00은 대상2개로 미클릭이다. 키메디/블루팜 저녁 예약은 이 배포용 스냅샷에 없다.

닥터빌 배포용 복구는17:34 인증 POST200·로그아웃 근거로 성공했지만 개발자용은21:18 판독0·제출0·221ms에 policy_rejected다. providerPath=other/callbackState=missing으로 기본 진입 주소 통일만으로 해결되지 않았다. 정확한 다른 경로는 기존 enum으로 특정하지 못한다. 후다닥·디톡스·키메디는 두 에디션의 이번 복구에서 인증을 확인했다. 배포용 출석4곳·퀴즈2개 완료는 기존 완료 판독이며 새 제출 증거는 없다. 개인 원본은 커밋하지 않는다.

## 변경과 유지 조건

- 닥터빌의 일반 텍스트 날짜는 기존 조회기에서 읽혔지만 입장기의 요소 선택에서 빠졌다. 전용 `.time .start`와 같은 카드의 제목/숨긴 내용/버튼을 제외한 날짜를 대조한다. 일반 텍스트·월-일 형식을 지원하고 다른 날짜·잘못된 요일·복수 시작·종료 시각 오인은 거부한다.
- callback 없는 제공자 기본 `/` 또는 `/login`만 전용 읽기로 분류한다. 이 좁은 읽기는 계정값·쿠키·URL 값·인증 증거를 반환하지 않고 제출/이동/후보 검증 권한이 없다. 보안 확인·추가 인증·정보 보완·비밀번호 폼이면 수동 확인으로 중단한다. 저장 계정의 제출 전 단계에서만 고정 PC 페이지1회 GET으로 원래 사이트 흐름을 재확인한다. 정상 로그인 경로가 복원되면 기존 두 준비 판독·영속 기록 뒤1회 제출한다. 기존 인증 근거가 있으면 비밀번호 복호화 없이 종료한다. 다른 경로·변형 callback·후보·제출 후에는 이 처리를 하지 않는다. 실제 개발자 경로가 이 조건인지 Windows 재확인이 필요하다.
- 메디게이트의 동일한 관찰 상세 링크·동일 신청 상태를 가진 읽기 전용 중복과 단일 입장 카드는 실행 가능한 카드로 연결한다. 링크 차이·등록/미등록/종료 차이·대상 식별 부재는 계속 모호성 중단이다. 보고된 실제 두 대상이 이 조건인지는 미확정이다.
- 블루팜의 PC 일정 보완은 사전 검사에만 연결돼 있었다. 정시 판독과 허용 클릭 목록에 연결하고 진행 중 표시·같은 날짜/시각·원래 참여 버튼·제출 전 영속 기록·불확실 재전송 금지를 유지한다.
- 입장 행의 선택적 `inspection`은 날짜/시각·대상·버튼·식별 개수와 읽기 전용 여부만 보존한다. 원시 주소·식별자·계정·원문은 없다. 기존 receipt·시도 형식은 그대로이며 실제 v15 reader의 읽기/다시 저장 호환을 확인했다. 사전 검사와 정시 실패의 원인을 구분할 수 있다.

## 검증과 한계

v15 원본으로 callback 없는 기본 제공자 복구와 일반 텍스트 날짜 조건의 실패를 재현했다. Node181항목·구문, 실제 Linux Electron45/Xvfb 합성 HTTPS 관리 창71·자동 작업28·계정97·입장53항목이 통과했다. 실제 Windows/인증 사이트와 합성 재현을 구분한다. 최종 묶음71/65·소스149파일 재현·15→16 동일 runtime 패치와 전체 서버 자산 다운로드를 검증했다.

실제 제공자의 다른 경로·사용자 강의 DOM·메디게이트 실제 식별 근거와 v16 로그인·정시 입장·영상·적립은 남은 Windows 확인이다. 보안 정책을 넓혀 원인을 감추거나 모호한 대상을 임의 클릭하지 않는다. 모바일·vendor v113·의존성·Electron45·계정/프로필/시도 기록·과거 자산을 유지한다. 닥터라운지 v114·지속 재생·시청시간/적립 우회는 포함하지 않는다.
