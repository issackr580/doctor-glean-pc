# PC 0.1.0-preview.47

닥플 플러스의 통합회원 로그인과 기존 세션 갱신을 구분한다. 첫 인증 요청의 429는 대기 헤더가 빠져도 기존 기본 대기를 적용한다. 수동 창의 두 요청은 최근 HTTP 상태와 시각만 오류보고에 표시한다. 계정 저장 직후의 별도 작업용 로그인은 다음 조회나 출석에서 실제 로그인 필요 상태가 확인될 때 진행한다. 실제 Windows에서의 닥플 로그인은 확인이 남았다.

같은 에디션의 작은 패치는 preview.20~46에서 선택된다. preview.46과 preview.47의 Electron 45 Windows 실행 환경을 대조하고, 기존 서명 피드의 호환 범위를 이어받았다. 개발자용은 브라우저에서 Draft 패치 ZIP을 받아 앱의 「받아 둔 패치 ZIP 설치」에서 고를 수 있다.

고정 실행 소스는 `d3e3d1a554f4a19541de72753d1dd5b86eaeaf2e`이며 태그는 `pc-source-v0.1.0-preview.47`이다. Node 514개와 구문 검사, Linux Electron 합성 HTTPS 1684개를 통과했다. 두 실제 Windows 묶음의 앱으로 Linux Electron 관리 화면에서 배포용 159개·개발자용 173개를 확인했다. Windows 설치와 실계정은 별도 확인이 남았다.

GitHub 서버 자산 12개를 다시 내려받아 크기·SHA-256·ZIP 전체 파일을 대조했다. 같은 두 패치로 업데이트 피드에 서명했다. [관리자 수동 업로드 기록](https://github.com/issackr580/doctor-glean-pc/actions/runs/46131640514)
