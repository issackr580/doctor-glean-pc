# 0.1.0-preview.27 — 최신 일정 반영과 미입장 예약 복구

## 변경

- PC-016/D26: 예약과 사이트 시각이 다르면 단일 관찰 상세의 날짜·완전 제목·첫 시작 시각을 두 번 확인해 예약·실행 창·타이머를 함께 수정한다. 같은 상세의 캐시 시각 차이만으로 포기하지 않는다.
- 옛 기한을 지난 실패/expired도 미시도·미소비면 복구한다. 진행 중 강의는 현재 ready를 요구하고, 새 시작+10분 뒤에는 명시적인 미래 종료시각까지 확인해 즉시 실행한다. 새 기한은 현재+10분과 종료 중 이른 값이다. 미래 강의는 아직 not_open이어도 재예약한다.
- 이전→새 시각과 예약 갱신/미입장 예약 복구를 표시한다. 기존 키·필수 원장·receipt/attempts/retries·취소/수동 입장/불확실·한미 슬롯은 보존한다. 이미 시도/소비한 입장은 반복하지 않는다.
- v1 예약의 선택적 identity 해시·최근8개 변경/복구 이력·종료시각과 개발자 prepare의 고정 schedule_updated를 추가한다. 진행 중 후보 우선·후보40건·다른 정시 작업 양보·중지/문서/조회/날짜 변경 무효화·저장 실패0클릭을 유지한다.
- 닥터빌 원래 판독기가 ready여도 PC의 엄격한 날짜·첫 시작/종료를 대조한다. 제목·끝 시각 숫자만 일치하면 클릭하지 않는다. 실제 입장은 원래 버튼과 제출 전 영속 기록을 다시 확인한다.
- 적용 범위는 닥터빌 일반 예약이다. 다른 사이트·모바일/vendor·한미 반복 정책·DPAPI·프로필·사이트/IPC 허용 범위·배포 공개 범위는 유지한다. 새 폴링·서버·일정 확인 중 계정 제출·자동 진단 전송은 없다.
