# PC 0.1.0-preview.30 — 입장 재확인·보안 로그인·개장 후 판독

닥터빌의 상세 제목 미발견 때 현재 원래 목록을 한 번 다시 읽고, 관측 단일 상세의 전체 제목·날짜·첫 시작 시각·원래 입장 버튼을 다시 확인한다. 이미 검증된 ID와 소비된 시도는 보존한다. em/b로 표시된 완전 제목을 읽되 부분 제목·이미지·표기 차이로 입장하지 않는다.

디톡스 최초 고정 목록 GET의 HTTP 로그인 이동은 차단하고, query 없이 기존 고정 HTTPS 로그인 GET만 페이지당 한 번 연다. 기존 계정 복구가 원래 목록으로 복귀하며 POST/입장·자격 dispatch 뒤·취소에는 재시도하지 않는다. 그 밖의 정책 차단을 연결 오류와 구분한다.

키메디 라운지는 개장 전 완료 표시로 종료하지 않고 00:01:03 후 새 GET으로 오늘 상태를 확인한다. 개발자 입장 진단은 9사이트를 포함하고 제목 후보 개수·이동 차단/연결 오류의 고정 종류만 기록한다. 사용자 데이터·계정/동의·예약/시도·기존 업데이트/서명·runtime과 모바일/vendor는 보존한다.

합성 반례: 최신 링크/동일 ID 복구, 다른 ID·잘못된 제목/날짜·중복·취소·저장 실패·소비 후 재실행, HTTP 로그인 대체 범위/1회 상한/복구 후 목록, 6/7 라운지의 개장 전 전일 완료와 개장 후 상태를 구분한다. 고정 입력·묶음·소스·패치·게시 결과는 게시 인계에서 별도 기록한다.

실제 Windows DPAPI·회원 DOM/로그인·입장/재생/출석/보상·알림/절전/업데이트 설치는 이번 합성 검사와 구분하며 미확인이다. 닥터빌 실사용 제목 미발견의 정확한 DOM 원인을 확정한 것은 아니다. Windows Authenticode와 PC Ed25519 업데이트 서명은 별개다.
