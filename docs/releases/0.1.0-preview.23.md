# PC 0.1.0-preview.23 — 닥터빌 상세 판독과 상태 구분

닥터빌의 고정 seminarDetail 경로·단일 숫자 seminarId에서 일반 제목 요소와 같은 작은 영역의 날짜·첫 시작시각을 함께 대조한다. 별도 소개/프로필의 날짜를 빌리지 않고 요일·다중 일정·잘못된 시작/끝 시각·중복 제목·추가 쿼리를 거절한다. 화면 요소의 CSS 클래스나 실계정 실패 원인은 캡처만으로 확정하지 않는다.

종료된 세미나입니다. 표식은 입장/신청 종료로 기록한다. 신청취소 버튼은 이미 신청된 상태의 읽기 전용 근거로만 쓰고 누르지 않는다. 미리보기 VOD 표식만으로 종료로 바꾸지 않는다. 목록에서 하나의 관찰된 상세만 읽은 뒤 원래 버튼을 기존 영속 기록 이후 한 번 실행하는 흐름과 종료 시0클릭을 합성 HTTPS에서 검증한다.

PC 전용 강의의 외부 플레이어·계정 생성·개인정보 동의·추가 인증은 별도 수동 단계다. 사이트/팝업 허용 범위를 확대하거나 동의·시청시간·적립 조건을 우회하지 않는다. 기존 계정/프로필·v1 저장·기한·한미5슬롯·취소/미확인 기록·에디션 분리·vendor v113·의존성을 유지한다. 모바일 소스·APK·서명·릴리스와 과거 PC 자산은 변경하지 않는다.

직접 Windows·인증 사이트의 실제 입장/영상/적립은 별도 확인이다. 공개 기록은 합성·기술·배포 근거만 포함하고 개인 원본·실사용 활동은 포함하지 않는다.
