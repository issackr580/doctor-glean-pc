# PC 0.1.0-preview.43

후다닥과 닥플 자동입장 및 입장용 복구를 중단한다. 디톡스는 기존 자동입장 중단을 유지한다. 종근당은 강의 조회만 지원한다. 구 예약과 시도·설정·계정을 보존한다.

닥터빌은 일반 조회에서 선택한 날짜와 관계없이 라이브 목록의 확인 가능한 원래 다음 페이지까지 읽는다. 수강일 전 신청 가능한 새 강의를 알리고 당일·마감·신청 완료는 제외한다. 학습 일정에서 **닥터빌 사전 신청**을 열면 원래 상세에서 직접 신청할 수 있다. 닥플은 열린 출석 달력의 완료를 추가 전송 없이 인정하며 복구 중 홈에서 공식 달력으로 인증을 한 번 확인한다. 사이트 요청 대기를 진단과 복구 안내에 남긴다.

설치한 앱에서 **설정·도움말 → PC 업데이트 확인**을 사용한다. 전체 설치용 Windows x64 ZIP과 같은 에디션의 preview.20~42에서 적용할 수 있는 app 패치를 준비했다. preview.42의 배포 자산과 새 런타임을 파일별로 대조하고 이전 서명 피드의 호환 범위를 이어받았다.

고정 실행 소스는 `ef7088edc3f4e3140031fb95af22cb19c12fd813`이고 태그는 `pc-source-v0.1.0-preview.43`이다. Node 506개와 구문이 통과했다. Linux Electron 합성 목록 170개·계정 124개·입장 493개와 Windows 빌드의 Linux 관리 화면 배포용 156개·개발자용 170개를 검사했다. 14일 뒤 강의를 2페이지에서 찾아 목록 조회 두 번에 GET 4회, 알림 1회였다. 수동 상세를 열 때만 GET 1회가 발생했고 신청 POST는 0회였다. 닥플 이미 열린 달력의 추가 전송과 대기 중 자동·수동 복구 요청은 0회였다. 실제 Windows·회원 사이트·포인트 및 OS 전체 전송량은 별도 확인이다.

두 에디션의 서버 자산 12개를 받아 크기·SHA-256·체크섬·ZIP 파일 목록을 대조했다. 두 에디션의 패치로 서명된 업데이트 피드를 갱신했다. [수동 GitHub Actions](https://github.com/issackr580/doctor-glean-pc/actions/runs/46110290092)
