# 0.1.0-preview.19 — 취소 중 오류와 팝업 진단

Windows PC판 수정·배포용 공개 prerelease·개발자용 협업자 전용 Draft 게시를 완료했다. 실제 Windows 팝업의 원문/예외가 없어 정확한 오류명·원인은 미확정이다. 개인 보고 원본과 실사용 시각·사이트별 활동은 공개 기록에서 제외한다.

## 변경

원본의 두 bounded 함수에서 이미 취소된 신호가 늦은 load/evaluate 실패를 관찰하지 않아 미처리 rejection이 되는 조건을 strict Node로 재현했다. 취소/기한 뒤에도 시작한 비동기 결과를 소비하고 재실행·재제출하지 않는다. 이 별도 재현을 실제 Windows 팝업과 같은 원인으로 단정하지 않는다.

일반 오류보고에는 현재 프로세스 최근10개 고정 오류 종류·알려진 PC src 파일/행/열을 메모리로만 남긴다. uncaughtExceptionMonitor는 Electron/Node의 기본 예외 처리·팝업·종료를 유지하며 새 자동 제출을 중지한다. 처리된 예외도 원래 오류를 전달해 저장 실패와 일반 오류를 구분한다. 기존 계정·수동 창·시도 기록을 보존한다.

개발자용 기존7일 opt-in 기록기만 같은 최소 오류와 실행 버전을 기존2000개/일·4MiB 한도 안에서 보존한다. 배포용에는 추가 기록기·개발자 preload/IPC/UI가 없다. 원문·stack·절대 경로·URL·계정·쿠키·토큰은 저장하지 않으며 자동 전송은 없다. 직접 재시도 개발자3초/배포10초·자동60초/15분3회·사이트별 하루10회·불확실 재제출 중단을 유지한다.

## 검증과 한계

Node201·구문, 실제 Linux Electron45/Xvfb 합성 HTTPS 관리 창78·자동 작업30·계정103·입장54를 통과했다. 실제 native load/evaluate 창 파기·늦은 reject·기본 치명적 예외 종료 유지·안전한 필드/위치·기록기 off/재시작·시도와 수동 창 보존을 확인했다. 최종 Windows 묶음 관리 창 개발자78/배포72·에디션 분리·깨끗한 소스155파일 재현·18→19 동일 runtime 패치를 확인했다.

실제 Windows 팝업 재발·DPAPI·계정/조회/정시 입장·영상/적립은 추가 실사용 검증 대상이다. 합성 통과를 실제 성공으로 확대하지 않는다. 모바일 소스·APK·서명·릴리스·vendor v113·의존성·Electron45와 과거 자산은 변경하지 않았다.
