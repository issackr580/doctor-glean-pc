# PC 배포용 0.1.0-preview.35

Windows PC판 preview.35에서 목록 복귀 시 기존 문서를 확인하고, 자동 목록의 반복 리디렉션을 사이트별로 중단합니다. 인터엠디 공개 전 자동 조회와 닥터빌 설문 백그라운드 접속을 줄입니다.

Linux Electron 합성 검사 1,182건과 Node 453건이 통과했습니다. 한미 입장 모의 응답 검사는 첫 실행 실패 후 같은 소스의 재검사에서 통과했습니다. Windows 실기기 절전과 실계정 결과는 미확인입니다.

Windows x64 신규 설치에는 전체 ZIP을, 기존 preview.34 배포용에는 작은 패치를 사용하세요. 패치를 수동 적용할 때는 트레이에서 앱을 종료하고 ZIP에 포함된 패치 안내를 따라주세요.
