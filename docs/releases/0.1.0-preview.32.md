# 0.1.0-preview.32 — 평일 입장 판독·재확인 개선

[PC-022 분석](../NOV11_ENTRY_REVIEW.md)을 따른다. 닥터빌 공식 ID 상세의 장식용 굵은 글씨를 제목과 분리하고, 메디게이트 신청완료 카드의 관측된 단일 공식 상세를 유틸리티 링크와 구분한다. 같은 실패의 일정 준비에는 제한된 재확인 간격을 두며 정시 입장은 유지한다. 경고 원문 없이 로그인/신청 필요를 기록하고 같은 문서에서 기존 계정 복구 경로에 전달한다.

예약 key·계정·선택·시도/취소/unknown·반복/일정·영수증·DPAPI·에디션/사이트 세션·서명키·업데이터 형식은 유지한다. 모바일과 vendor는 변경하지 않는다. 디톡스 상세 누락과 실제 Windows/실계정 입장·시청·출석/보상은 미확정이다.

후보 상태이며 최종 소스·검사·빌드·서버 자산 검증과 공개/Draft URL은 게시 단계의 별도 기록으로 확정한다. 과거 ZIP/태그/자산을 교체하지 않는다.
