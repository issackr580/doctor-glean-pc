# 0.1.0-preview.32 — 평일 입장 판독·재확인 개선

[PC-022 분석](../NOV11_ENTRY_REVIEW.md)을 따른다. 닥터빌 공식 ID 상세의 분류·강연자 굵은 글씨를 제목과 분리하고, 메디게이트 신청완료 카드의 관측된 단일 공식 상세를 유틸리티 링크와 구분한다. 같은 실패의 일정 준비는 제한된 간격으로 다시 확인하며 정시 입장은 유지한다. 경고 원문 없이 로그인/신청 필요를 기록하고 같은 문서에서 기존 계정 복구에 전달한다. 직접 입장의 관측은 빠른 문서 이동 전에 전달하고 폴링과 중복 제거한다. 내장 프레임과 오래된 문서 경고는 계정 복구 신호가 아니다.
