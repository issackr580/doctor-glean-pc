# 0.1.0-preview.13 — 조회 범위와 실행 시점 검증

2026-10-27. 작업 중이며 아직 게시하지 않았다.

## 보고와 수정

추가 Windows v12 TXT/개발자 JSON은 내보낸 시각 외 현재 상태가 같다. 조회9곳 중 후다닥만 로그인 필요이며 이전 login_required 이후 자동 재시도 제한 때문에 이번 제출은 없다. 다른5사이트는 이번 저장 계정 복구의 인증 상태를 확인했다. 전체 조회 실패 또는 모든 자동 로그인 실패로 해석하지 않는다.

한미 클릭·이동5회는 13:10~13:50 기록이고 앱 v12는15:08 시작했다. 영상 inaccessible·적립 미확인이다. 점심 닥터빌3건·메디게이트·키메디는 미클릭, 저녁10건은 예약만 있으며 v12 정시 실행/사전 검사 결과는 아직 없다. 과거 기록을 v12 성공으로 소급하지 않는다.

- 디톡스 달력의 checked 상태·선택 날짜/월, 현재 목록 판독·추가 목록 수를 보고서와 저장소까지 보존한다. 사이트·날짜가 일치한 실제 판독 근거만 분류하고 전체 목록 완전성으로 승격하지 않는다. 현재 목록 확인/날짜 범위 확인/실패를 화면과 복사 일정표에서 구분한다.
- 범위를 확인하지 못한 빈 결과가 기존 강의·예약 근거를 지우지 않게 한다. 확인된 정상 빈 목록은 갱신하고 실패한 목록은 저장된 목록으로 표시한다.
- 이 사이트만 조회와 명시적인 저장 계정 로그인 동작을 사이트 행에 제공한다. 기존 프로필·동의·영속 시도·횟수 제한과 실패한 자동 로그인 중단을 유지한다.
- 예정 예약 일괄 사전 검사는 오늘의 선택된 사이트·시작 전 예약만 최대40건·2분간 순차 판독한다. 계정 복구/입장/재생/제출 잠금 변경은 없고 정시 작업·전체 중지에 양보한다. 처리·건너뜀·중단 결과를 표시한다.
- 이번 프로그램 시작 전/후 클릭 수를 구분하고 이전 결과 시각을 표시한다. 저장된 기록과 실제 PC 실행·영상·사이트 적립을 분리한다.
- Electron 실행기가 종료 코드만으로 통과하지 않고 이번 로그의 완료 표식·실제 항목 수를 확인하게 한다. 잘못된 합성 fixture 초기화로 결과가 생성되지 않은 경우를 통과 처리하지 않는다.

## 검증과 한계

Node165·구문 검사를 통과했다. 실제 Linux Electron45/Xvfb 합성 HTTPS 관리 창70·자동 작업28·계정90·PC 입장24항목을 확인했다. 첫 관리 창 검사의 잘못된 과거 이력 fixture는 저장 형식 검증에서 중단됐고 완료 보고서가 생성되지 않았다. fixture를 수정하고 재실행한 새 완료 표식과70항목을 확인했다. 실행기도 완료 표식이 없는 종료를 실패로 처리한다. 최종 두 에디션·12→13 패치·깨끗한 소스와 게시 확인은 준비 후 기록한다.

기존 v12 보고의 판독 실패 원인은 인증된 실제 화면을 확보하지 못했으므로 미확정으로 유지한다. 후다닥 실패 계정·실제 정시 입장·영상·출석/적립은 Windows 재확인이 필요하다. 닥터라운지 v114 이식·지속 재생을 추가하지 않는다. 모바일 소스·APK·릴리스·vendor·의존성·Electron45는 변경하지 않는다. 개인 보고서 원본은 커밋하지 않는다.
