# PC 0.1.0-preview.38

Windows x64 preview.38입니다. 디톡스 편성표에서 카드가 화면에 표시된 날짜 열과 HTML 부모가 다른 경우를 처리합니다. 해당 날짜를 끝까지 확인한 경우에만 이전 목록을 교체합니다. 닥터빌 자동 입장은 같은 강의의 채널 선택 창에서 기존 선택을 유지한 채 확인을 한 번 누르고, 대기실 도달을 별도로 표시합니다. 다른 사이트를 조회한 뒤 닥터빌 일정을 다시 읽던 동작도 줄였습니다.

새 설치에는 전체 ZIP을 사용하세요. 기존 설치에는 같은 에디션의 패치를 사용하세요. 합성 예제에서 확인한 결과이며 실제 Windows 재시작·회원 사이트의 재생·출석은 별도 확인 대상입니다.

소스 커밋 `724f86b163443f8f214ff01f5d911e74d3ffd8eb`. Node 검사 460개 및 Linux Electron 45 합성 검사 1,367개가 통과했다. 최종 전체 검사 전에 닥터빌 로그인 화면 전환 검사가 두 차례 실패했고 같은 커밋의 최종 전체 검사가 통과했다. 서버에서 두 에디션의 자산 12개를 내려받아 크기와 SHA-256을 대조하고 모든 ZIP 내부 파일을 로컬 검증본과 비교했다. 같은 에디션 preview.20~37에서 직접 패치를 적용할 수 있다.
