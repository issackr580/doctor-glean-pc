# PC 0.1.0-preview.22 — 예약·조회 목록의 수강 신청

아직 PC 입장을 시도하지 않은 예약에 신청하기를 추가한다. 한미는 미신청 강의가 자동 입장 예약에 없더라도 조회 목록에서 신청할 수 있다. 현재 저장된 강의의 고정 키로 요청하고 원래 사이트 창에서 제목·날짜·시작시각과 단일 신청 버튼을 새로 대조한다. 이미 신청됐으면 읽기만 한다. 동의·개인 입력·결제·추가 인증은 사이트에서 직접 마친다.

신청 버튼 실행과 신청 완료를 구분한다. 최종 단계를 마친 뒤 신청 창의 신청 마침 · 상태 확인 또는 앱의 신청 상태 확인을 사용한다. 실제 완료 근거를 확인하고 창을 마친 뒤 목록을 갱신하며, 설정과 원래 기한 안의 미소비 예약만 다시 준비한다. 기존 취소·입장 시도·불확실 기록을 지우거나 지난 기한을 연장하지 않는다.

신청 시도는 별도 registration-attempts-v1.json에 먼저 기록한다. 같은 강의를 예약/조회 양쪽에서 눌러도 같은 신청으로 묶는다. 기록 실패0클릭·미확인 뒤 자동 재제출0회·현재 URL/문서 세대·취소/중지·소유 창을 유지한다. 기존 v1 계정/입장/진단 파일 형식과 에디션별 프로필·DPAPI·한미5슬롯·사이트 허용 범위·vendor v113·의존성은 유지한다. 모바일 소스·APK·서명·릴리스는 변경하지 않는다.

합성 HTTPS에서 원래 신청 처리기의 POST·제출 전 저장·숨긴 복제/중복/시간/제목·상태 충돌·개인 입력/동의/결제·재시작·재확인·기존 예약 보존을 검증한다. 실제 Windows/인증 사이트의 신청·정시 입장·적립은 별도 확인이다. 공개 기록에는 합성/기술/배포 근거만 포함하고 개인 활동·원본 보고를 넣지 않는다.
