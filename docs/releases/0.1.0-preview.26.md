# 0.1.0-preview.26 — 예약 시작 시각 불일치 구분

## 변경

- PC-015/D25: 목록의 모든 제목 후보에 날짜가 없을 때, 같은 사이트·날짜·제목의 단일 관찰 상세 링크는 조회 시작 시각이 달라도 읽기 힌트로 사용한다. 서로 다른 ID는 기존 시각과 일치하는 후보가 있어도 중단한다.
- 새 상세의 독립 날짜·제목·첫 시작 시각을 원래 예약과 다시 대조한다. 단일 시작 시각만 다르면 예약과 사이트의 시작 시각이 다르다고 표시한다. 힌트의 schedule_changed와 새 상세의 target_missing + scope_changed를 구분한다.
- 기존 예약 시각·기한·시도·취소/소비 기록은 유지한다. 새 사전 검사보다 오래된 실패는 이전 실행으로 표시한다. 사전 검사 클릭·계정 제출·필수 시도 소비는0회다.
- 모바일·vendor·의존성·DPAPI·사이트/IPC 허용 범위·에디션 분리를 유지한다. 원문/URL/ID·자동 전송·자동 재예약은 추가하지 않는다.

## 검증과 게시

검증·고정 소스·전체/작은 패치·소스 ZIP 해시와 공개/협업자 Draft 확인은 완료 후 기록한다. 합성 검증과 실제 Windows·인증 사이트 입장/영상/적립은 별개다.
