# PC 0.1.0-preview.46

닥플 플러스 로그인 화면이 남았거나 사이트가 대기 중이면 「로그인 마침」에서 창을 유지한다. 합성 응답에서 후속 조회는 로그인 실패 및 서버 대기 중 0회, 정상 로그인 뒤 1회였다. 오류보고는 제한 응답의 요청 종류, 수동 창·작업 창·읽기 API, HTTP 메서드를 구분한다. 실제 Windows 계정 저장과 출석은 추가 확인이 남았다.

개발자용의 Google 로그인은 기본 브라우저에서 진행한다. 같은 에디션의 작은 패치는 preview.20~45에서 설치할 수 있다. preview.45와 preview.46의 Electron 45 Windows 실행 환경 해시를 대조하고, 기존 서명 피드의 호환 범위를 이어받았다. 이전에 Google 로그인 창에서 멈췄다면 브라우저에서 Draft 패치 ZIP을 받아 앱의 「받아 둔 패치 ZIP 설치」에서 고른다.

고정 실행 소스는 `30b1219facc8f8768aaad4b93fb05e4d8acf90cd`이며 태그는 `pc-source-v0.1.0-preview.46`이다. Node 513개·구문 검사와 Linux Electron 합성 HTTPS 1677개를 통과했다. 최초 실행에서 중단된 닥터빌 SPA 타이밍 검사는 같은 소스로 다시 실행했다. 두 실제 Windows 묶음의 앱으로 Linux Electron 관리 화면에서 배포용 159개·개발자용 173개를 확인했다. Windows 설치와 실계정 Google 로그인은 별도 확인이 남았다.

GitHub 서버 자산 12개를 다시 내려받아 크기·SHA-256·ZIP 전체 파일을 대조했다. 같은 두 패치로 업데이트 피드에 서명했다. [관리자 수동 업로드 기록](https://github.com/issackr580/doctor-glean-pc/actions/runs/46128579264)
