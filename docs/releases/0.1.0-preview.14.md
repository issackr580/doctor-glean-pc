# 0.1.0-preview.14 — 사전 검사 준비 대기와 일정 대조

2026-10-27. 배포용 공개 prerelease와 개발자용 협업자 전용 Draft 게시를 완료했다.

## Windows 보고와 변경

추가 v13 TXT/개발자 JSON은 내보낸 시각 외 현재 상태가 같다. 일괄 사전 검사10건은 모두 처리됐지만 준비 성공10건이 아니다. 키메디·인터엠디는 대상 확인 후 시작 전 버튼 대기, 닥터빌5건·메디게이트1건은 카드0, 한미·블루팜은 제목1·일정0으로 중단됐다. 사전 검사 제출0이며 정시 실행 결과는 없다. 한미 과거 클릭5회는 현재 버전 성공으로 소급하지 않는다.

닥터빌 복구는 provider 경로에서 판독0·제출0·약348ms에 unknown, 조회는 약45초 time_limit다. 기존 강의5건은 저장된 목록으로 보존됐다. 주소 정책·문서 교체·응답 중 정확한 원인은 기존 보고서로 확정하지 않는다. 후다닥의 이전 실패 뒤 자동 재시도 제한은 유지한다. 디톡스 선택일 달력 checked 정보는 실제 Windows에서 보존된 것을 확인했다.

- 사전 검사는 최대8초 읽기를 반복하고 안정된 대상·버튼을 확인한다. 문서 교체는 새 문서에서 다시 읽고 로그인/provider는 별도 상태다. 계정 복구·입장·재생·예약/제출 잠금 변경은 없으며 정시 작업·중지에 양보한다.
- 한미는 원래 PC 조회 판독의 인접 날짜 묶음 기준을 사용한다. 날짜 셀·요일·시간·단일 제목·인접성·숨긴 행/다른 날짜 경계를 확인하고 모호하면 중단한다. 원래 입장 판독이 대상/버튼/모호성에서 중단한 경우만 보완하고 기존5슬롯·기한·영속 잠금 뒤 원래 버튼을 사용한다. 잘못된 슬롯은 거부한다.
- 블루팜의 같은 카드 메타데이터에 있는 연속 기간은 시작 날짜·시각을 대조한다. 다른 일정·거꾸로 된 종료·시작 시각 부재는 거부한다. 선택일 달력 checked 근거는 그 날짜 범위 확인으로 보존하며 사이트 전체 완료로 확대하지 않는다.
- 일괄 처리 수와 버튼 확인·시작 전 대기·로그인·확인 필요를 구분한다. 개별 사전 검사의 판독 횟수를 남긴다.
- 계정 trace에 고정 실패 코드와 허용 이동 boolean을 보존한다. 계정·URL·callback 값·원문·쿠키는 추가하지 않으며 허용 경로·인증 근거·횟수 제한을 완화하지 않는다.

## 검증과 한계

Node173항목·구문 검사, 실제 Linux Electron45/Xvfb 합성 HTTPS 관리 창71·자동 작업28·계정90·PC 입장35항목이 통과했다. 늦게 표시되는 실제 DOM, 날짜 묶음의 요일/숨긴 경계/충돌, 연속 기간·잘못된 종료·복수 일정, 한미 보완 클릭의 슬롯별 제출 전 기록·다음 슬롯 보존, 사전 검사0제출·취소·정시 양보와 실패 정보의 비밀값 제외를 확인했다. 최종 Windows 묶음 관리 창 개발자71/배포65·에디션 분리, 깨끗한 소스146파일의 의존성 설치·Node173·구문 재현과13→14 동일 runtime 패치를 확인했다.

실제 사용자 화면의 정확한 DOM·닥터빌 로그인 중단 원인은 미확정이다. 합성 재현은 Windows의 이번 로그인·정시 입장·영상·출석/적립 성공으로 확대하지 않는다. 지속 재생·시청시간 보장·닥터라운지 v114 이식은 추가하지 않았다. 모바일·vendor·의존성·Electron45·기존 계정/프로필/시도 파일과 과거 자산은 변경하지 않는다. 개인 보고서·공개 페이지 원문은 소스에 넣지 않는다.
