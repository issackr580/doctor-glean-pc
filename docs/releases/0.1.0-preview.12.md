# 0.1.0-preview.12 — 예약 검증과 PC 실행 근거

2026-10-27. 배포용 공개 prerelease와 개발자용 협업자 전용 Draft 게시를 완료했다.

## 사용자 보고와 변경

개발자용 v11과 별도 배포용 v10 Windows 보고를 구분해 검토했다. 한미의 PC 클릭/이동5회와 영상 미확인, 닥터빌의 날짜·시각 대조 실패, 메디게이트 중복 대상, 키메디의 버튼 부재/별도 사용자의 미신청을 서로 다른 단계로 남긴다. 출석·퀴즈 기존 완료는 PC 신규 제출·모바일 기여로 단정하지 않는다. 개인 원본은 커밋하지 않는다.

- 예약 수·대기·PC 클릭 강의/회차·확인 필요를 표시하고 대상 확인·클릭·이동·영상·출석/적립을 분리한다. 기존 완료와 PC 시도 이력, 오전 점검 종료와 사이트별 성공을 구분한다. 조회 선택이 필요한 자동 입장 사이트를 안내한다.
- 명시적인 상태만 확인은 완료 캐시도 새로 읽고 별도 읽기 전용 창을 사용한다. 자동 수령 실행과 상태만 확인 모드를 화면·진단에서 구분한다. 자동 실행의 완료 중복 제출 방지는 유지한다.
- 예약별 사전 검사는 별도 읽기 전용 작업 창을 사용한다. 저장 계정 복구·입장 클릭·재생·실행 시도 예약을 하지 않는다. 검사 결과만 별도 필드에 저장하고 정시 작업에 양보한다.
- 개발자 동의 이력에 자동 작업의 예약·판독·재시도·제출 전 기록·결과, 익명 작업/실행 식별자·버전·예정/실제 시각·고정 수치·boolean을 추가한다. 계정·URL·원문은 제외하고 기존7일·일일2000개·4MiB 한도를 유지한다. 한도 도달을 표시한다. 배포용에는 이 추가 기록기를 넣지 않는다.
- 재시도 과정의 최근5개 결과를 보존하고 현재 실행판을 과거 결과의 실행 버전으로 소급하지 않는다. 내보내기 시각·프로세스 시작·빌드 기준·선택 조회 사이트를 추가한다. 기존 ledger·계정·프로필·시도 제한은 유지한다. 기존 영속 receipt 형식을 바꾸지 않고 예약의 선택 필드만 추가한다.
- 원본 입장 판독이 대상/버튼/모호성에서 중단한 경우에만 PC 보완 판독을 사용한다. 같은 카드의 보이는 날짜·시작 시각·제목을 대조하고 숨긴 과거 날짜·제목 속 시각을 사용하지 않는다. 메디게이트 중복은 관찰한 동일 강의 상세 식별자와 상태가 모두 같을 때만 합친다. 서로 다른 식별자·알 수 없는 인자 차이·미신청·보안 확인은 계속 중단한다. 클릭은 원래 제공자 버튼과 기존 제출 전 영속 잠금을 따른다.
- 후다닥 등 이전 실패 뒤 자동 재시도가 멈춘 이유를 안내한다. 한미·메디게이트처럼 현재 인증 POST 경로를 관찰하지 않는 사이트는 요청 관찰 미지원 boolean을 내보내며 요청 수0을 미전송 증거로 해석하지 않는다.

## 검증과 미확정

Node24.19.0/npm11.9.0에서 `npm test`와 구문 검사, 별도 `node --test --test-isolation=none test/*.test.js`의 실제155항목이 통과했다. 제한 환경의 파일 단위 집계20개를 제품 검사 수로 사용하지 않는다.

실제 Linux Electron45/Xvfb 합성 HTTPS는 관리 창65·자동 작업28·계정90·PC 입장24항목이 통과했다. 사전 검사0클릭·계정 복구0회·예약/ledger 불변, 취소와 정시 양보, 실제 DOM의 숨긴 날짜/중복 URL/다른 식별자·미신청·시각 불일치, PC 보완 클릭 전 영속 기록과 불확실 재제출0회, 진단 실패의 작업 비간섭·비밀정보 제외를 확인했다. 컨테이너 OS sandbox 제약으로 검사에만 `--container-no-sandbox`를 사용했으며 제품의 원격 sandbox·contextIsolation·webSecurity·TLS는 유지했다. 최종 Windows 묶음의 관리 창 개발자65/배포59와 같은 appData 상위 경로의 저장소 분리를 확인했다. 깨끗한 소스144파일에서 의존성 설치·Node155·구문 검사를 재현했고 11→12 패치의 동일 runtime을 확인했다.

원래 인증된 사용자 화면을 이 환경에서 읽지 않았으므로 보고된 날짜/시각 대조 실패·버튼 부재의 정확한 DOM 원인은 미확정이다. PC 보완 판독의 합성 재현 통과를 Windows 성공으로 확대하지 않는다. 한미·메디게이트 실패 계정의 인증 근거를 완화하지 않았다. 닥터라운지 구성 변경과 모바일 v114 이식, 지속 재생은 남은 별도 작업이다. 모바일 소스·APK·서명·릴리스·vendor·Electron45.0.0·의존성은 변경하지 않는다.
