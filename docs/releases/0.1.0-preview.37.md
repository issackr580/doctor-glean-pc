# PC 0.1.0-preview.37

Windows x64 preview.37입니다. 닥터빌·인터엠디 등에서 자동 강의 조회 중 세션이 만료되면 안내 팝업을 조용히 처리하고, 복구가 허용된 계정으로 한 번 로그인한 뒤 선택한 날짜의 강의 목록을 다시 확인합니다. 데이터 사용 설정과 사이트가 지정한 대기 시간은 예약 작업과 업데이트에도 적용합니다.

새 설치에는 전체 ZIP을 사용하세요. 기존 설치에는 같은 에디션의 패치를 사용하세요. Windows 실기기와 회원 사이트의 실제 로그인·입장 결과는 별도 확인 대상입니다.

소스 커밋 `61eaa4b75dd78b15cc659054c7d0386c64ed8e35`. Node 검사 457개 및 Linux Electron 45 합성 검사 1,265개가 통과했다. 서버에서 두 에디션의 자산 12개를 내려받아 크기와 SHA-256을 대조하고 모든 ZIP 내부 파일을 로컬 검증본과 비교했다. 같은 에디션 preview.20~36에서 직접 패치를 적용할 수 있다.
