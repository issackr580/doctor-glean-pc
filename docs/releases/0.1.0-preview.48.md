# PC 0.1.0-preview.48

닥플 계정 저장용 임시 창의 공식 로그인 문서에서 페이지 방문 기록 요청만 생략한다. 합성 환경에서 방문 기록은 0회, 로그인과 세션 갱신은 각각 1회 도착했다. 수동 창과 공식 인증 요청은 기존 서버 대기를 지킨다. 실제 Windows의 닥플 계정 저장은 확인이 남았다.

고정 실행 소스는 `1892bf55116dcde2257182009f3d64e0afd46d72`이며 태그는 `pc-source-v0.1.0-preview.48`이다. Node 514개와 구문 검사, Linux Electron 합성 HTTPS 1693개를 통과했다. Windows 묶음의 앱으로 Linux 관리 화면을 실행해 배포용 159개와 개발자용 173개를 확인했다. 실제 Windows 설치와 실계정 확인은 별도다.

두 에디션의 서버 자산 12개를 다시 내려받아 크기, SHA-256, 전체 ZIP 내부 파일을 대조했다. 동일한 Electron 45 런타임의 preview.47 묶음에 패치를 적용할 수 있게 확인하고, 기존 호환 버전을 서명 피드에 이어받았다. [관리자 수동 업로드 기록](https://github.com/issackr580/doctor-glean-pc/actions/runs/46173652160)
