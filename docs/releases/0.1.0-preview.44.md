# PC 0.1.0-preview.44

닥터빌은 그날 첫 조회에서 사전 신청 목록 끝까지 읽는다. 최근 전체 조회에서 날짜 순서를 확인한 경우 최대 3시간 동안 현재 페이지의 공식 ID·날짜·시각·제목·신청 상태·페이지 이동이 이전과 일치하고 선택일을 지나면 이후 페이지를 생략한다. 목록이나 로그인 세션이 달라지거나 처음 조회하는 날짜, 앱 재시작, 3시간 경과 후에는 다음 일반 조회에서 목록을 다시 확인한다. 일정 아래 **닥터빌 사전 신청 → 전체 확인**에서 직접 요청할 수 있다. 마지막 전체 확인 시각을 표시한다.

기존 앱의 **설정·도움말 → PC 업데이트 확인**에서 올린다. Windows x64 전체 ZIP과 같은 에디션의 preview.20~43에서 적용할 수 있는 패치를 준비했다. preview.43의 실제 배포 ZIP과 새 패치의 실행 환경을 파일별로 대조하고 이전 서명 피드에서 확인한 호환 범위를 이어받았다.

고정 실행 소스는 `cf11c9df129c4a91ba65f4890860aee3e534b841`이며 태그는 `pc-source-v0.1.0-preview.44`이다. Node 508개와 구문, Linux Electron 합성 HTTPS 1639개와 두 Windows 묶음의 Linux 관리 화면 배포용 158개·개발자용 172개가 통과했다. 2페이지 합성 목록에서 연속 두 번 조회한 GET이 4회에서 3회로 줄었으며 강의 일정과 이전 사전 신청 후보를 유지했다. 수동 전체 확인에서는 2페이지를 다시 읽었고 같은 강의를 재알림하지 않았다. 실제 Windows 설치와 회원 사이트의 전송량·응답 시간은 별도 확인이다.

두 에디션의 서버 자산 12개를 받아 크기·SHA-256·체크섬·ZIP 파일 목록을 대조했다. 두 에디션의 패치로 서명된 업데이트 피드를 갱신했다. [수동 GitHub Actions](https://github.com/issackr580/doctor-glean-pc/actions/runs/46116811084)
