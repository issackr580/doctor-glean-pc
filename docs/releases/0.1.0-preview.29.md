# PC 0.1.0-preview.29 — v139 기준 기능 연결

배포용 공개 prerelease·협업자 전용 developer Draft·서명 피드를 확인했다. [기능 차이와 적용 계약](../PORTING_V139.md), [수용 항목](../PORTING_V139_ACCEPTANCE.json)을 따른다.

닥플 C01/LIVE 조회와 신청 완료 공개 ID별 입장, 후다닥/디톡스3회·한미5회, 퀴즈별 fuse·종근당 daily lease·6/7 라운지, 설문 읽기/알림/제외, 일일 선택·메모·보고 미리보기·외부 host 설정을 PC host에 연결했다. 기존 프로필·Windows DPAPI·선택·시도·PC 서명 updater를 유지한다. 진단/조회/업데이트로 소비된 외부 동작을 초기화하지 않는다.

최종 검증은 고정 입력 verify:pc와 두 Windows resources/app의 합성 관리 창·에디션 분리·전체/작은 패치·깨끗한 소스 재현으로 기록한다. 고정 입력 검사 수는 Node321·구문·Linux Electron45/Xvfb 관리115·자동30·계정121·입장272·replay136·신청193·업데이트23이며 Electron 전체890개다. 소스210파일이며 모바일 검사 수는 포함하지 않는다. 입력 SHA·Windows 묶음/깨끗한 소스 재현·게시 결과는 게시 인계에서 별도로 기록한다. Windows DPAPI·실계정·실제 입장/재생/보상·Windows 알림·절전/복귀/재부팅과 실제 GitHub 로그인/버튼 설치는 별도 실측이다. Android APK/서명/키·개인 자료는 포함하지 않는다.
