# 0.1.0-preview.7 인계·릴리스 기록

2026-10-26. 소스 기준 태그는 `pc-source-v0.1.0-preview.7`이다. 빌드·소스 ZIP의 manifest에 실제 Git commit을 기록하며 SHA256SUMS는 배포 자산을 기준으로 한다.

## 문제와 결과

일부 계정은 로그인 제출 ACK 뒤3번째 읽기에서 blocked가 됐다. 지연된 원래 POST와 redirect로 재현했고, 결과 확인 요청이 로딩 완료 전 주소에 연결되는 순서를 고쳤다. 로딩 완료 후 새 URL·문서 세대를 캡처한다. 오래된 읽기는 다시 관찰하며, 오래된 문서의 비밀번호 전달은 실행하지 않는다. 같은 로그인 POST는 재전송하지 않는다.

허용된 인증 팝업은 같은 격리 프로필을 유지하고 후보 결과 확인은45초로 제한한다. 검증 범위·origin 제한을 풀지 않는다. cooldown의 다음 가능 시각을 표시하고 단계·문서·고정 신호만 진단에 남긴다. 저장 후 자동 복구 동의가 있으면 작업 프로필도 확인하고 그 사이트 목록을 갱신한다. 기존 저장 계정과 시도 이력을 유지한다.

## 공동작업 기준

CONTRIBUTING·STATUS·ARCHITECTURE·DECISIONS·RELEASE_PROCESS와 PR/오류보고 양식을 추가했다. Node24/npm11, 고정 Electron, 잠금 파일, 에디션 분리·검증 수준·개인정보 제외·저장 호환·PR 기준을 문서화했다. 로컬 검사 실행기와 허용 목록 소스 ZIP을 제공한다. CI는 수동 예시만 포함하고 자동 게시/예약/비용 발생 서비스를 연결하지 않는다.

사용자가 소스 공개와 배포 위치를 승인했다. PC 전용 공개 저장소 `issackr580/doctor-glean-pc`에 같은 기준 커밋·태그·소스 ZIP과 distribution 릴리스를 연결한다. 본인용 developer 실행파일과 사용자 자료는 공개하지 않는다.

## 검증 범위

- Node119 항목 통과, 구문 검사 통과.
- 실제 Linux Electron·합성 HTTPS: 관리 창 개발자59/배포54, 자동 작업20, 계정36항목 통과. 최종 빌드의 파일 해시를 검증한 소스와 대조했다.
- 계정36항목에는 원래10사이트 처리기, 지연 POST 회귀, 허용 인증 팝업/다른 목적지 차단, 오래된 문서의0회 비밀번호 전달, 작업 프로필 복구와 비밀정보 제외가 포함된다.
- 사용자 Windows 보고에서5사이트 계정 검증·DPAPI 저장이 확인됐다. 이번 빌드의 남은 사이트·실제 저장 계정 복구·입장/적립 성공은 추가 확인 단계다.
- 원본 Android와 이전 릴리스/실행물은 변경하지 않는다.

공동작업자는 CONTRIBUTING과 STATUS에서 시작한다. 관리자가 쓰기 권한을 초대하고, 외부 개발자는 fork 후 PR을 보낸다. 개인 developer 실행물은 기존 본인 전용 초안으로 유지하고 distribution은 새 PC 저장소에 검증판으로 게시한다.
