# 0.1.0-preview.33 — v156 입장 정책과 읽기 경로

현재 검증 중인 PC 후보이며 게시 완료를 뜻하지 않는다. [PC-023 적용/이관·API 검토/측정 범위](../PORTING_DIRECTION_V156.md)·D32를 따른다.

디톡스 자동입장을 중단하고 기존 계정·조회·수동 작업·설정·과거 전송/회차는 보존한다. 한미는 시작0/25분, 새25분의 명확한 실패에만 조건부35분·각90초이며 구10분 회차와 key/ID/취소/unknown/소비를 보존한다. 이관 전 불투명 로컬 snapshot, 내부 workflow schema2와 새 ledger32~34로 구 callback·구 앱 자동 재개를 막는다. 이전 snapshot을 최신 시도 원장에 덮어쓰지 않는다.

종근당 월/일·닥플 LIVE 읽기를 정확한 PC 인증/프로필·전체 페이지·ID/일정/상태·원래 예산 안에 연결하고 실패 때 기존 화면1회로 이어간다. 원래 링크가 없으면 ID로 URL을 조립하지 않고 화면을 유지한다. 메디게이트 집계·키메디/기타 API·상태 변경 API는 검토이며 신규 write/heartbeat/보상 전송은 없다. 숨은 읽기의 명백한 media GET만 제한하고 이미지/캡차/API/POST/수동·입장 화면을 보존한다.

실행 결과는 최종 고정 입력 검사와 패키지/서버 검증 뒤 기록한다. 합성 성공과 익명 종근당 계약 확인은 Windows/DPAPI·회원 로그인/입장/시청/출석/보상·버튼 설치와 다르다. API/관측 브라우저 본문·page/dispatch·창 생존 수치는 OS 전체 전송량·실제 재생시간이 아니며 절감률은 미확인이다. 모바일/vendor·PC updater/helper/서명키는 변경하지 않았다.
