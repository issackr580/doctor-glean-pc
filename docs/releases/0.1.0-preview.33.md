# 0.1.0-preview.33 — v156 입장 정책과 읽기 경로

[PC-023 구현·이관·API 검토·수용 경계](../PORTING_DIRECTION_V156.md)·D32를 따른다. 디톡스 자동입장은 중단하고 계정·조회·수동 이용·설정·과거 전송/회차는 보존한다. 한미는 실제 시작0/25분, 새25분 회차의 명확한 실패에만 조건부35분·각90초다. 구10분 회차를 새 회차로 재명명하지 않고 key/ID·취소/수동/unknown·소비를 유지한다. 이관 전 불투명 로컬 snapshot, 내부 workflow schema2와 ledger32~34로 구 callback·구 앱의 옛 정책 재개를 막는다. **옛 snapshot을 최신 소비/unknown/취소 기록 위에 덮지 않는다.**

종근당 월/일·닥플 LIVE 읽기를 정확한 PC 인증/프로필·전체 페이지·ID/일정/상태·원래 예산 안에 연결한다. 실패만 기존 화면1회로 이어가고 stale은 폐기한다. 원래 링크가 없으면 ID로 URL을 만들지 않는다. 닥플 회원 원래 링크 필드·메디게이트 집계·키메디/기타 API는 별도 실제 계약 확인 전 검토다. 상태 변경 API·heartbeat/시청/보상 생성은 추가하지 않았다. 숨은 읽기의 명백한 media GET만 제한하고 이미지/캡차/API/POST/수동·입장 화면을 보존한다.
