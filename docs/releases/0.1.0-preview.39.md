# PC 0.1.0-preview.39

Windows x64 preview.39입니다. 메디게이트 자동 입장은 외부 강의 사이트의 주소를 별도로 허용할 필요 없이 같은 달의 수강 집계를 확인합니다. 원래 입장 버튼을 한 번 실행한 뒤 집계가 늘면 작업을 종료합니다. 이번 달 행사 주소를 공식 화면에서 찾고, 표시되지 않으면 앱에서 직접 지정할 수 있습니다.

닥플 출석 상태와 로그인 복구 후 강의 목록은 HTTP를 먼저 사용합니다. 조회가 입장 예약으로 중단되면 이미 완료한 사이트는 다시 열지 않습니다.

새 설치에는 전체 ZIP을 사용하세요. 기존 설치에는 같은 에디션의 패치를 사용하세요. 실제 Windows 설치·재시작과 회원 계정의 수강 집계는 별도 확인 대상입니다.

소스 커밋 `59cdd70a24f15064877c45df97a0ee89090b8564`. Node 검사 466개 및 Linux Electron 45 합성 검사 1,449개가 통과했다. Windows 묶음의 관리 화면은 개발자용 155개와 배포용 141개를 확인했다. 서버에서 두 에디션의 자산 12개를 내려받아 크기와 SHA-256을 대조하고 모든 ZIP 내부 파일을 로컬 검증본과 비교했다. 같은 에디션 preview.20~38에서 직접 패치를 적용할 수 있다.
