# 0.1.0-preview.28 — 버튼 업데이트와 개발자용 GitHub 로그인

## 변경

- PC-017/D27: 사용자가 누른 확인→다운로드·업데이트로 작은 패치를 검증·설치하고 앱을 재시작한다. 배포용은 직접 받고 개발자용은 별도 앱 내 GitHub 로그인 후 비공개 Draft를 받는다.
- 고정 서명 피드의 Ed25519 공개키·패치 SHA/크기·채널/에디션/상향 버전·호환 목록·전체 app/runtime 파일을 대조한다. ZIP 경로 탈출·링크·암호화/중복·Windows 별칭·크기 초과는 거절한다. 서명 개인키·GitHub PAT는 앱/소스/공개 workflow에 넣지 않는다.
- 강의/계정/조회·사이트 창 작업과 임박한 입장은 먼저 처리한다. 설치 전 새 실행을 막고 helper ACK·부모 종료 후 app 전체를 교체한다. 새 관리 UI 시작까지 실행을 유보하며 실패 시 이전 app으로 복구한다. 로그인·설정·예약·필수 시도 데이터와 기존 기록은 바꾸지 않는다.
- 개발자 GitHub 창은 별도 프로필·Node/preload/관리 IPC 없음·sandbox/contextIsolation/webSecurity/TLS 유지다. 로그인/2FA 값은 읽거나 입력하지 않는다. 고정 Draft/첨부만 사용하고 공개 배포물에는 GitHub 로그인 구현이 없다.
- 이전 앱에서 이번 버전까지는 같은 에디션 작은 패치를 한 번 수동 적용한다. 이후 같은 runtime은 버튼 업데이트, runtime 변경은 전체 묶음을 안내한다. 상주 업데이트·자동 게시·새 서버·모바일/vendor 변경은 없다.

## 검증과 게시

현재 입력 검증·고정 소스·두 에디션·전체/작은 패치/소스 ZIP·재다운로드/접근 경계·서명 피드는 완료 뒤 기록한다. 실제 Windows 폴더 교체·재시작/복구 및 실제 GitHub 로그인/2FA는 별도 확인이다.
