# 0.1.0-preview.17 — 제목 날짜 제외와 PC 입장 보완

2026-10-27. Windows PC판 수정이며 검증한 고정 소스에서 두 에디션을 준비한다.

v16의 닥터빌 제공자 세션 재확인·일반 텍스트 날짜 판독, 메디게이트의 관찰 가능한 동일 강의 중복 판정, 블루팜 정시 보완 연결과 값 없는 inspection을 유지한다. [v16 기록](0.1.0-preview.16.md)의 실제 Windows 근거·보안 조건·미확인 범위를 따른다.

마지막 검토에서 `.tit` 외 지원 제목 heading에 날짜가 있고 실제 강의 날짜가 없는 카드가 잘못 대조되는 합성 조건을 발견했다. v17은 모든 지원 제목 요소를 날짜 판독에서 제외한다. 같은 카드의 별도 날짜·전용 시작 시각이 확인돼야 클릭 가능하다. 원래 v16 코드로 이 실패를 재현했고 해당 조건을 실제 Electron 회귀 검사에 추가했다. 이미 공개된 v16 자산·태그는 유지한다.

Node181·구문, 실제 Linux Electron45/Xvfb 합성 HTTPS 관리 창71·자동 작업28·계정97·입장54항목이 통과했다. 최종 묶음·소스·16→17 패치와 게시 검증 결과는 완료 뒤 추가한다.

실제 개발자 닥터빌의 다른 제공자 경로와 강의 DOM·메디게이트 식별·v17 Windows 로그인/정시 입장/영상/적립은 재확인이 필요하다. 합성 통과를 실제 계정 완료로 확대하지 않는다. 모바일·vendor v113·의존성·Electron45·계정/프로필/시도 기록·과거 자산은 변경하지 않는다. 닥터라운지 v114·지속 재생·시청시간/적립 우회는 포함하지 않는다.
