# PC-022: 11월 11일 입장 보고 분석과 수정

원본은 공개 PC main `8d8911e` / 실행판 preview.31(`8678d49`)이다. 별도 `fix/nov11-entry-evidence` 작업본과 소스 기준 스냅샷을 만들었다. Windows 보고의 버전·현재 프로세스·실행 journal을 대조했으며 첨부 원문·개인 제목/ID/주소·계정·인증은 이 저장소에 복사하지 않았다. 모바일 소스와 vendor 스냅샷은 변경하지 않는다.

## 보고에서 확인한 범위

- 현재 프로세스의 runtime fault·진단 저장 실패는0이다. 당일 조회는10곳 모두 종료했다. 조회 종료는 전체 강의 범위 확인이나 입장 성공을 뜻하지 않는다.
- 닥터빌 점심4개 예약은 제목1/날짜0/시각0으로 일정 대조에 반복 실패했고 외부 입장 시도는 없었다. 전날에도 같은 실패 형태가 있다. 저녁의 미래 예약은 실패에 포함하지 않는다.
- 메디게이트는 대상·날짜·시각이 일치했으나 신청완료 강의의 입장 버튼을 발견하지 못했다. 디톡스는 원래 카드의 상세 이동 뒤 제목을 놓쳤고 경고창 관측도 있다. 원문 없는 기존 보고로 경고 내용을 소급할 수 없다.
- 키메디·인터엠디·한미에는 클릭 및 허용 문서 이동 기록이 있다. 이것을 정확한 플레이어 도착·영상 진행·출석/보상으로 확대하지 않는다. 이미 완료된 출석·퀴즈를 PC 신규 제출로 계산하지 않는다.
- 입장 journal은 최근7일/최대50기록이며 일부가 생략됐다. 재시도 횟수와 서로 다른 강의 수를 구분한다. 신청 여부와 실제 회원 화면은 별도 확인이 필요하다.

## 재현한 반례와 변경

공식 ID가 같은 닥터빌 상세에서 분류명·강연자·인원까지 `strong/b/em`이면 기존 판독은 이를 복수 제목으로 세고 날짜 판독 전에 실패했다. PC 판독은 완전한 기존 제목을 우선하고, 같은 공식 ID에서 제목이 바뀐 경우에는 첫 독립 전체 날짜 앞의 제목을 같은 제한된 헤더에서 구한다. 장식 텍스트를 제목으로 중복 계산하지 않는다. 서로 다른 ID, 날짜·첫 시작 충돌, 제목의 시각/끝 시각, 중복 헤더, 로그인·종료·버튼/기한 조건은 별도로 유지한다. 날짜 대조를 없애거나 느슨한 제목 일치를 입장 권한으로 쓰지 않는다.

메디게이트의 대상 카드에 관심강의 등 유틸리티 링크가 함께 있으면 기존 엔진은 단일 상세를 고르지 못할 수 있다. PC 보완 판독은 신청완료·단일 대상·일정이 확인된 원래 목록 article 안의 관측된 공식 상세 링크 하나만 읽는다. 다른 ID·다중 ID·불명/토큰 query·미신청·날짜 불일치는 거부한다. ID로 URL을 조립하지 않는다. 상세 이동 후 독립 일정/버튼과 기존 원자적 저장·동일 worker/문서 결합을 다시 확인한다.

일정 재확인이 안정적으로 같은 대상을 놓치면 한 번의 읽기 대기 시간을 줄이고, 동일 링크/시각의 후속 확인은 시작10분 밖5분, 그 안1분 간격으로 다시 준비한다. 단순 조회 checkedAt 갱신은 간격을 초기화하지 않는다. 새 시각/상세·계정/선택/원장 epoch는 즉시 새 확인을 허용한다. 이 대기는 읽기 준비에만 적용하며 정시 입장 실행을 막지 않는다. 시도 소비·취소/unknown·재시도 이력을 초기화하지 않는다.

사이트 경고는 원문을 보관하지 않고 로그인 필요/신청 필요/수동 확인으로 분류한다. 같은 문서의 명시적인 로그인/신청 경고만 입장 판독에 전달하고 기존 동의 기반 계정 복구 wrapper가 처리한다. 경고를 수락하거나 인증/클릭 권한을 만들지 않는다. 새 문서·dispatch 뒤에는 이전 경고를 쓰지 않는다. 디톡스는 공식 ID 미지원 legacy이며 이번 보고의 실제 상세 누락 원인은 미확정이다.

개발자 journal에는 official/legacy 구분과 상세 제목 수·독립 날짜/시각 수·버튼 경계 누락·잘못된 날짜 등의 제한된 개수를 추가한다. 기존 v1 receipt/예약 저장 형식은 유지하며 배포용 기록기나 자동 전송은 추가하지 않는다.

직접 입장 직후 빠른 문서 이동이 기존 폴링보다 먼저 일어나면 관측 큐가 사라지는 경쟁도 실제 Electron 회귀에서 재현됐다. 메인 프레임의 기존 격리 관측 세계에만 고정 알림을 연결해 신뢰된 원래 클릭 관측을 전달하고 폴링과 중복 제거한다. main world/다른 프레임에는 알림 함수를 노출하지 않으며 임의 URL/명령/자격/제출 IPC는 없다. 기존 수동 창 보호와 취소·소비는 유지한다.

## 검증과 남은 확인

새 반례는 실제 PC 주입 번들과 EntryRunner/LocalState/WorkflowStore를 사용하는 합성 HTTPS로 실행한다. 메디게이트의 원래 상세 GET→영속 기록→1회 제출, 상세 날짜 변경0제출, 반복 호출0추가 제출, 닥터빌 제목 변경·장식/중복/오류 일정, 경고 분류·문서 교체를 포함한다. 일정 재확인 간격·새 시각 우선·취소·필수 원장 불변도 PC 정책으로 검사한다. 최종 항목 수와 배포 검증은 [v32 기록](releases/0.1.0-preview.32.md)에 남긴다.

사용자 Windows 보고와 합성 재현은 별개 근거다. 이 변경으로 실제 Windows 회원 로그인·해당 강의 입장/시청/출석·보상 성공을 확인했다고 표현하지 않는다. 다음 평일 보고에서 닥터빌의 독립 날짜/시각 수와 입장 후 이동, 메디게이트 상세 이동/클릭, 디톡스 경고 분류를 따로 확인한다. 이미 완료/미신청 강의와 실제 PC 미입장을 구분해야 한다.
